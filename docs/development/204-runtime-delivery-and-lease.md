# 204 · 实现边界与整批入口

当前基线为203轮已回读的七个独立仓库提交。源码、相关当前／沿用结果、原始角色失败及27份用户文件从实际工作区读取。工具诊断不得从203轮模型自述推导原图表错误原因；新观察必须有本轮结构化事件与实际文件佐证。

整批包含：受信输入解析错误类型、静态安全诊断映射、Codex工具执行状态及有界审计事件；实际交付失败与真实恢复；任务续租及授权锁的完整调用约束；Web／Desktop关键活动保留与客户反馈。代码和计划用例完成后记录源码摘要，随后才执行构建／类型／相关用例、原生数据库／Codex、实际页面、公司模型和部署检查。

未解决的交付状态以同一企业／任务的最新受信工具事件为准，补充资料或新原生回合不清除失败。Worker以当前任务身份读取结果，并在最终成功写入前再次核对；只有实际同工具完成才解除该项状态，不删除部分文件、既有预算或真实用量。

保持原费用规则：真实已发生用量保留；权限或参数错误不意味着此前模型调用免费；外部操作未知时不重复；受信输入解析发生在副作用之前才允许明确修正。领域错误仅公开静态定义的说明，其他错误只给通用有界分类。原异常及校验消息可能包含客户内容、路径或密钥，不能直接发送到模型、用户事件或日志。

服务器网络保持规则见[既有约束](../governance/05-server-network-preservation.md)。原102条及32组参照[上轮完整追溯](../quality/integrated-round-203/requirements-102.md)，本轮增量不会自动关闭专业、外部或生产要求。
