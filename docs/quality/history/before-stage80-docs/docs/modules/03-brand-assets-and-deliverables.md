## 1. 资产模型

Asset 表示业务资产，AssetVersion 表示不可变文件版本；Artifact 将版本关联到任务交付。BrandVersion 引用具体 Logo、字体、颜色、产品资料及规则。重复上传相同字节可以在同企业内复用对象，但跨企业不能通过文件摘要获知或读取他方文件。

此处 BrandVersion 属于客户创作品牌，与 [CopyPaste 平台 UI 主题](../product/07-brand-design-system.md) 分开。预览面板及操作栏使用平台 token，作品按客户 brief 和已冻结的品牌版本渲染；切换平台浅深主题不写入客户工程、不修改导出色彩/字体，也不自动增加 CopyPaste Logo 或水印。

云工作区增加 WorkspaceNode，表示可浏览的目录树与文件位置，文件节点指向 AssetVersion；执行器路径不是业务文件身份。会话附件、会话工作文件、项目资料和交付产物分开标识，UI 允许有权限的引用和提升。逻辑文件持久化不依赖独占运行机器。

选区反馈包含基版本和文本/图像区域/视频时间段锚点。继续修改创建新任务和新版本，基版本冲突返回 VERSION_CONFLICT。存入项目时明确可见对象，不能通过移动文件隐式扩大源资源授权；共享产物不默认共享完整私有会话、记忆和凭证。可编辑类型和保真范围按实际支持逐项声明。

每个版本保存 MIME、字节数、SHA-256、图片宽高/媒体时长、存储位置、来源、使用范围、创建人和父版本。文件名仅用于显示，不用于权限和唯一身份。

## 2. 上传与下载

申请上传 → 获取短期传输授权 → 上传字节 → complete 提交校验 → 服务核对对象大小、摘要和真实类型 → 隔离检查 → ready。上传 session 默认 24 小时失效；未完成分片按清理任务回收。

文件状态为 pending_upload、processing、ready、rejected、deleted。处理中的文件不能作为已可用输入；恶意文件名、压缩包越界、解压超量、超大像素和宏执行均应被限制。表格解析不执行公式或宏。

下载先做归属及角色校验，再发短期 URL 或受控代理。高敏感资源采用每次鉴权代理；普通签名 URL 默认 5 分钟有效，需明确在其有效期内无法仅靠角色撤销立刻收回已签发链接。

## 3. 品牌资料字段

| 分类 | 字段与规则 |
| --- | --- |
| 标识 | 品牌名、Logo 版本、允许变体、最小尺寸和留白 |
| 色彩 | 主辅色、背景/前景组合，保存颜色值和用途 |
| 字体 | 字体文件/系统标识、字重、字符覆盖、来源和使用范围 |
| 文案 | 繁中/英文口吻、产品事实、禁用表达、需审核的主张 |
| 产品 | SKU、名称、真实图片、价格/促销有效期、不可变事实 |
| 交付 | 常用渠道、语言、尺寸、安全区、文件命名和输出类型 |

更新发布新 BrandVersion，任务默认冻结当前版。价格到期等事实可以在执行前触发明确校验；不静默改变已经审阅通过的历史素材。

## 4. 可编辑工程

本产品初始承诺为「能在本产品恢复编辑」，通过可版本化 layout/timeline 描述保存。PSD、AI、AE、剪映等格式需要独立适配与验收，不能从 JSON 编辑描述推断任意专业软件兼容。

图片工程至少包含 canvas、background、image layers、text layers、font_asset_version、位置尺寸、裁切、安全区、z-order 和输入版本。坐标以画布逻辑像素表示，每个输出尺寸有独立布局；文本保留 Unicode 原文，颜色与字体引用确定版本。

视频工程至少包含帧率、总帧数、素材、轨道、片段入出点、字幕、音量与效果版本。工程与媒体文件分别作为资产保存，缺少引用素材时显示不可恢复原因。

最小机器格式见 [图文工程](../contracts/creative-project.schema.json)、[视频工程](../contracts/video-project.schema.json) 和 [交付清单](../contracts/delivery-manifest.schema.json)。默认开放这些格式与版本化模板可表达的编辑；新增裁切、动效参数等时同步升级 schema、渲染器及验收，不通过额外未验证字段执行功能。

## 5. 交付包 manifest

交付包包含实际文件、`manifest.json` 和适用的编辑描述。manifest 字段：package_version、task_id、brand_version_id、locale、输出规格、文件相对路径、SHA-256、来源资产版本、字体/音源引用与可编辑范围。

打包路径必须为相对路径，禁止 `..`、绝对路径或用户本机路径。签名 URL 不写成永久依赖；打包器将获准文件复制到包内或明确列为需重新授权的外部依赖。

## 6. 审阅、清理与故障

接受操作绑定 artifact_version 和用户；已接受版本不可原地覆盖。修改创建新版本及依赖关系。部分交付可下载，但 package manifest 必须标明缺少哪些规格。

删除先将在线访问禁用，再清理对象、缩略图、提取文本、索引、编辑工程中的内容副本和缓存。其他项目合法引用同一企业对象时先解析引用政策；用户请求完整项目删除时不能因隐藏引用无限期保留正文。

存储故障时不发布缺文件的 ready 版本。最终化用暂存对象、摘要核对和数据库引用提交；孤立对象通过扫描清理，数据库引用缺失有告警。

验收覆盖同名文件、多版本、缺字字体、过期促销、损坏上传、引用删除、跨企业下载以及可恢复编辑。

## 7. 后台内容控制接入

REQ-090/091/097 要求全部资产、品牌、资料、成果及编辑工程接入 [Admin 资源控制器](../technical/11-admin-control-plane.md)。元数据、正文、下载、新版本、隔离、分享撤销和生命周期删除分别鉴权；内容管理员可在获授范围直接管理，客服默认无正文权限。修改产物创建带父引用的新版本，历史文件不可覆盖；隔离同步阻断检索、模型读取、分享和下载。恢复依据当前权限，不恢复旧公开链接。财务、权益和审计使用独立领域命令，不能当作普通资料修改或删除。
