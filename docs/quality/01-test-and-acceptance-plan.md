## 4. 三类客户验收脚本

1. 素材：品牌资料 → brief → 18 单元图文批次 → 局部修改 → 接受 → 导出 → 恢复编辑。另验收一条真实模板视频，后续逐项增加生成式能力。
2. 复盘：导入/正式同步 → 口径确认 → 固定快照 → 指标复算 → 报告数字回溯 → 确认素材关联 → 新一轮测试 brief。
3. 流程：成功任务 → 固定模板 → 手动复用 → 定时运行 → 设备离线/外部异常 → 恢复与对账 → 查看完整费用。

每类先选 10 个代表任务建立基线，不把小样本当统计显著性。客户接受须由客户代表记录，技术任务 succeeded 不自动计入接受率。

## 5. 故障注入重点

在事务提交前后、供应商接受请求后但回包前、对象写入后但元数据提交前、队列重复投递、租约切换、取消竞争、设备重连与 token 撤销处分别中断。检查权威状态、外部 operation、费用预留与真实文件，不仅检查 HTTP 返回码。
