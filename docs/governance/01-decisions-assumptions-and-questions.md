## 3. 必须实测的技术门槛

G01：锁定 Codex 版本在内部网关及原有模型/推理要求下完成完整工具循环、流事件、恢复、停止和费用验证；拒绝非 Codex 配置与内核覆盖，不自动改选内核。G02：图片接口返回真实文件并满足选定编辑操作。G03：模板视频真实可播放并通过字幕、尺寸、音画校验。G04：正式平台账户可取数和撤销，报表可复算。G05：权限、费用、断线和恢复跨层一致。

Web M1 增加会话/文件/技能/工作模式边界验证；M2 增加项目共享、专业分工、总预算及关闭客户端后的云端计划。M3 增加 G06：扩展对话/附件、上传版本绑定、休眠恢复、可选原生配对及资源回收；M4 增加 G07：打包 Desktop 的本机 Codex、完整权限、文件/终端工具、停止恢复及签名更新。G01 同时覆盖本机与云端 Codex 集成；原有门槛和 TC 不删除。模拟接口不替代上述证据。

G08（角色发布）：Codex 固定版本技能加载、内部 Image 2 实际生成/编辑与分层排版；至少十二个不同角色含开发、设计和指定设计师，每个具备完整任务、修改和依赖/权限异常运行证据。具体拆分为 REQ-073–080，见 [角色分册](../product/06-role-templates-and-skill-presets.md)。当前证据状态 not_run。

G09（品牌设计）：按 [品牌规范](../product/07-brand-design-system.md) 核对官网基础色/Logo、衬线与无衬线层级、组件、两主题、繁英、关键状态、375/768/1024/1440px、键盘/对比/缩放和客户作品隔离。M1 Web 首验，M3/M4 分别验扩展和 Desktop；取样与静态样板通过不代表实际产品运行通过。对应 REQ-081/082，当前产品证据状态 not_run。

G10（管理后台）：M1 验独立身份与 MFA、完整用户/用量、人工费用/VIP、生效与到期、内容和任务控制、细粒度权限及事务审计；M2 验批量逐项权限/部分成功、导出字段/下载重验和公开配置发布回滚。需覆盖重复入账、超额退款、越权授予、正文/成本字段、审批载荷、到期调度失效、跨端缓存与旧 worker。工作包 AD01–AD10 见 [后台技术设计](../technical/11-admin-control-plane.md)，TC-083–102 均为 not_run。

这些答案不影响文档体系完成；会影响实施配置、版本计划和采购。
