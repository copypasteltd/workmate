# 第 197 轮：连接恢复与本机结果审阅

本轮沿用完整目标的 32 组、102 条原始要求。先完成以下整批代码和文档，再统一构建、测试、调试、实机检查及发布。不得以本轮检查替代未完成的专业业务或生产验收。

| 编号 | 本轮实现 | 完成依据 |
| --- | --- | --- |
| 197-01 | Desktop 公司接口采用隔离的 Electron 原生网络会话；登录、控制请求、上传、下载、媒体及更新共用同源限制 | 系统代理兼容、禁止跳转、不共享浏览器 Cookie；实际安装包验证 |
| 197-02 | 所有客户端统一识别连接中断；只读请求最多自动重试一次；写入保留结果未知提示 | 连接中断、响应已接收、写入已提交但响应丢失、用户取消分别验证 |
| 197-03 | 本机心跳仅在最后确认的有效租期内有限重试；服务不可用与账号切换分别处理 | 不重复模型或工具，不复活过期租期，不忽略授权拒绝 |
| 197-04 | 未准入原生执行回合的启动失败，在服务端持久证明无任何计费／工具准入后自动释放预留 | 任务和执行锁、已有启动协议、零准入证明、审计事件；已准入或未知用量仍待核账 |
| 197-05 | 本机执行记录折叠长指令和输出；退出码及失败状态保持可见；准确标示截断 | 记录绑定任务、原始活动保留、预览继续验证本机授权 |
| 197-06 | Web 软件检查仅在任务工作台显示一次 | 实际页面与窄屏检查；保留独立 Desktop 云任务页面的必要入口 |
| 197-07 | 修复 Linux 回执缺少宿主耗时后的非法显示；同步所有软件检查和创意矩阵耗时位置 | 真实测量或原规范时间，未知返回 null；各端不显示 NaN、负数或虚构零；整批修正后统一复验 |

公司模型请求继续走公司服务器。网络会话调整针对 Desktop 主进程 HTTP；本机 Codex 的独立推理连接仍受原有公司网关与凭据约束，不能用界面网络测试代替推理实测。

已准入回合即使暂未观察到模型费用，也不能自动推定没有本机操作；本轮不改写既有未知账务记录。全部失败尝试原样保留。正式证据、实际媒体、部署与 Git 发布结果在本轮开发文档和质量报告中补充。

整批联调修正 197-07：Linux 执行耗时优先读取真实宿主测量，缺失时使用原执行回执的规范开始／结束时间；无法确认则为 null。Web 与 Desktop 不把缺失、负数、无穷或非法值显示成 NaN 或零。同步检查矩阵导出的同类耗时显示。此修正完整编码后再统一复验，既有失败和发布包保持。
