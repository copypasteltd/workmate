# 用户与企业管理：新建、删除及列表批量操作

本轮落实用户管理及企业管理的完整操作入口，取代原来只能查看目录、进入详情修改状态的流程。最高管理员直接执行，其他角色遵循已发布策略；所有敏感操作核对当前权限、范围、批量上限及最近十分钟的 MFA。

| 编号 | 要求 | 实现行为 |
| --- | --- | --- |
| DIR184-01 | 新建用户 | 填写显示名称、工作邮箱及原因；邮箱规范化、去重；建立一般用户，标记管理员创建。用户登录仍须完成邮箱验证码验证，不授予后台权限。 |
| DIR184-02 | 新建企业 | 填写企业名称、明确选择有效的既有用户作为擁有人，并命名首个项目；企业、擁有人关系、账务账户和项目在同一事务中建立。 |
| DIR184-03 | 删除用户 | 每行提供永久删除入口；移除显示名称、联系邮箱及标签，撤销会话、刷新凭据及企业身份关联，移除成员和项目授权；保留不可重新启用的身份标记。 |
| DIR184-04 | 删除企业 | 每行提供永久删除入口；立即停止企业接收新工作，接入持久化清理队列，清理项目及云端内容；清理进度在内容管理中可追踪。 |
| DIR184-05 | 列表多选 | 两个列表均提供逐行勾选、全选当前页、已选数量及取消选择；搜索、筛选、翻页、刷新或切换目录后丢弃旧选择，不隐含选择其他页。 |
| DIR184-06 | 批量状态 | 用户批量启用或冻结并撤销登录；企业批量启用或暂停。已关闭账户重新开放继续走原有单账户审批流程。 |
| DIR184-07 | 批量删除 | 两个列表都支持删除所选记录；明确显示记录、数量及版本，输入 `DELETE 数量` 并确认保留范围，填写原因后先预览再提交。 |
| DIR184-08 | 批量一致性 | 每次最多100条，界面只选当前页；冻结明确的 ID/版本。任一记录不存在、版本变化、范围不符或不符合删除条件，则整批不发生业务变更。企业后续清理分别持久化执行。 |
| DIR184-09 | 归属与费用保护 | 不允许删除某个有效企业全部可用的最后擁有人；须先移交或删除该企业。有在途工作或未结算预留的用户须先处理完成。删除不调整余额、退款、费用预留或审计。 |
| DIR184-10 | 权限与审批 | 分离用户新建、用户删除、企业新建、企业删除四项权限；默认仅扩展内置最高管理员，其他角色由管理员明确授予。删除按账户关闭策略审批，创建企业按高权限成员变更策略审批。 |
| DIR184-11 | 可恢复提交 | 预览五分钟有效，确认绑定原始命令摘要及记录版本；提交使用幂等键。响应丢失后用同一确认、同一键重试，返回原操作，不重复新建或删除。 |
| DIR184-12 | 完整审计 | 保存原申请者、真实执行者、原因、冻结命令、策略版本、目标及结果。业务效果、审计和幂等结果在同一事务提交；审计写入失败即回滚全部目标。 |

删除用户针对平台登录身份和账户资料，不删除其他团队仍在使用的企业内容；历史账务、管理操作及审计身份引用保留。旧邮箱日后可以重新验证并创建全新身份，但不能复活已删除的旧账户。删除企业不删除全局用户账户，也不处理客户电脑上的本地文件。清理完成但保留法定及共享范围时，清理记录可显示“完成但有例外”，须结合实际异常列表和保留项目解读。

两个目录中的删除入口统一进入新流程。后台原有的“输入企业 ID 直接清理”提交端口返回明确引导，防止绕过审批和预览；完整项目的独立清理及客户自身的企业删除入口继续遵守各自授权规则。

新增业务目录应采用同样的多选、明确动作、预览、幂等及结果回执规范。账本、审计、消耗记录等属于保留事实，其操作以查询、导出及各自专用的更正流程为准。
