# 受控客服补充约束：来源、选择版本与本机客户授权

继承原 REQ-095 与 [限时只读支持方案](../technical/51-controlled-read-only-support.md)，不删改原始需求或完整验收条件。

| 编号 | 当前产品约束 | 关联需求 |
| --- | --- | --- |
| SUPPORT133-01 | 支持正文同时满足实际管理员身份、当前权限、明确企业／项目、当前客户授权及服务端截止时间。 | REQ-003／094／095 |
| SUPPORT133-02 | 任务原始来源隔离、到期或擦除后，保留的提示词／结果不能通过客服入口继续返回；诊断不得继续显示来源衍生标题。 | REQ-090／091／095 |
| SUPPORT133-03 | 所选正文绑定明确任务及当前内容版本；服务端和页面都拒绝旧版本与迟到响应覆盖新选择。 | REQ-094／095／098 |
| SUPPORT133-04 | 客户可在实际 Desktop 安装包界面创建、查看与撤销限时授权；管理员页面继续留在独立 Admin，不能接管客户登录。 | REQ-039／048／095 |
| SUPPORT133-05 | 只读支持不新增任务、模型调用、预算预留、费用、VIP 或客户凭证。私人会话正文不开放。 | REQ-048／094／095 |
| SUPPORT133-06 | 代码、双语说明、实际截图／GIF／视频及原始失败报告绑定同一轮交付；完整待办保留编号。 | REQ-055／060／098 |

行为、接口条件、来源处理与执行边界见 [阶段133技术方案](../technical/133-controlled-support-source-and-native-access.md)。真实数据源和媒体模型继续按用户要求使用假数据，不把合成测试结果标成生产模型验收。
