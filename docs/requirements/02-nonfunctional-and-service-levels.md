# 非功能要求与服务指标

版本：1.5 · 2026-10-18。以下数值为可调整的设计和验收基线，尚未经压测或客户合同确认。

## 1. 负载与测试条件

基准场景：10 个企业、50 个已登录用户、20 个同时交互用户、10 个运行中的 Agent 任务、2 个视频渲染任务；每个企业有 10,000 条素材元数据、100,000 条标准化报表数据。使用固定测试集，记录服务器规格、数据库规模、网络、缓存及接口版本。

API 延迟不包含模型生成、外部平台等待和媒体编码，须分别统计。执行器与业务 API 独立限并发，避免媒体任务挤占成员、任务查询和取消操作。

## 2. 性能、资源与默认限制

| 指标 | 设计目标 | 验证方式 |
| --- | --- | --- |
| 普通列表/详情 | P95 ≤ 800ms；错误率 < 1%，不含主动鉴权拒绝 | 在基准负载执行 30 分钟，并记录慢查询 |
| 任务接受 | P95 ≤ 2s，返回持久 task_id；上传单独计时 | 数据库提交后再返回接受响应 |
| 首个持久状态事件 | 接受后 P95 ≤ 3s | 以服务器时间关联接受与事件记录 |
| 页面使用 | 首屏优先文本和缩略图，视频懒加载；列表超过 200 行分页/虚拟化 | 375、768、1440 像素和浏览器缩放检查 |
| 普通资料上传 | 默认单文件 100MiB；媒体 1GiB，分片与断点续传 | 超限前提示；校验实际字节与服务端类型 |
| 图片批次 | 默认每批最多 60 个交付单元 | 拆批、局部重试与费用预留测试 |
| 企业并发 | 默认 2 个 Agent 执行槽、1 个视频任务；团队成员共用配额 | 协调者等待时释放槽，子任务不得重复预留总预算；两企业争用不得永久饥饿 |
| 浏览器资源 | 默认每任务最多 3 个任务标签页、每执行器 2 个上下文 | 正常和异常结束后回到基线，无无主页面 |
| 本地监听 | 默认最多 5 个授权目录；防抖 2s，按文件内容指纹去重 | 连续写入、临时文件、重启和自触发循环测试 |

模型及媒体能力的耗时、尺寸和并发上限，以内部服务实际能力注册表覆盖。产品先展示范围和排队状态；压测后再为特定能力给出生成时间目标。

## 3. 可靠性与恢复

M2 目标服务可用性为月度 99.5%，属于设计目标。监控口径为登录后可提交并查询任务的业务探针；计划维护、上游不可用及降级策略需在合同中明确，不默认排除故障以美化指标。

正常进程重启时，已经数据库提交确认的任务和费用记录应保持完整；队列可由 outbox 重建。灾难恢复目标 RPO ≤ 15 分钟、RTO ≤ 4 小时，须实际演练，不能与正常重启的零丢失目标混淆。

Worker 挂掉后回收执行租约，检查步骤和外部作业记录再恢复。消息传递按可能重复设计；业务状态变更、费用记账和外部副作用分别幂等。结果未知的外部写入进入对账或人工处理，不直接重放。

## 4. 安全与隔离

所有请求在服务端解析身份和企业成员资格；请求中的 tenant_id 不能直接成为授权依据。数据库查询及对象访问均验证归属，RLS 作为纵深措施；运行服务不使用数据库 owner、superuser 或 BYPASSRLS 角色。

凭证加密保存，日志不含 OAuth token、原生文件完整路径或供应商密钥。平台操作的权限撤销对新调用立即生效；已被外部系统接受的动作无法假定可撤销，必须显示实际结果。

本地执行采用原生受限进程、目录授权和程序白名单；进程隔离不等同虚拟机。没有可靠原生隔离能力时，只开放结构化、受限工具，不开放任意 shell。

## 5. 数据生命周期默认值

| 类别 | 初始默认 | 删除规则 |
| --- | --- | --- |
| 原始文件、生成产物及编辑描述 | 项目内 90 天，可按方案调整 | 立即逻辑不可访问，在线副本清理目标 24 小时 |
| 报表快照及任务事件 | 90 天 / 30 天 | 删除时处理快照、索引和导出副本；事件可保留脱敏骨架 |
| 原始模型请求及详细工具内容 | 默认不长期保存；故障诊断授权后最多 7 天 | 脱敏、限定访问与到期清理 |
| 操作审计及财务相关记录 | 初始 365 天，具体保留政策另行确认 | 必要记录最小化；不把删除素材等同删除所有账目 |
| 备份 | 滚动 35 天 | 正常轮换到期；恢复后重新应用删除账本 |

这些默认值是产品设计选择，不构成法律适用判断。客户合同、处理区域和保留例外按项目确认。涉及个人或商业敏感数据时，必须说明内部服务及其下游处理路径。

## 6. 可访问性、语言与兼容

交互以 WCAG 2.2 AA 为设计目标，正式符合性需专项评估。主要操作支持键盘，错误有文本描述，图表提供数据表，录制/生成视频的字幕可访问。支持 reduced-motion，不仅用颜色区分任务状态。

REQ-081/082 要求最终视觉采用 [CopyPaste 品牌规范](../product/07-brand-design-system.md)。官网浅深基础色精确保留，正文对比目标 4.5:1，大字及必要非文字控件 3:1；官网较淡装饰边框仅作分隔，输入、选择和焦点另用增强边界。静态 token 对比核查不替代完整组件和页面评估。

覆盖浅/深/跟随系统、375/768/1024/1440px、100%/200% 缩放、繁中英文与缺字体回退，检查导航、输入、角色、会话/成果、表格及弹层。三端复用视觉资源；客户作品保留其品牌，主题改变不得变更任务/编辑工程或导出内容。

Web 首期支持当前及前一个稳定版本的 Chrome/Edge；Safari 的文件能力使用上传下载降级。扩展仅声明经验证的 Chrome 最低版本。Desktop 先验证 Windows 11 x64 原生路径，macOS 按相同规范增加验证；正式系统矩阵由 M0 客户样本确定。

日期在数据库存 UTC，显示使用项目 IANA 时区，香港默认 `Asia/Hong_Kong`；当前文档日期按用户会话的 `Asia/Taipei`。界面和交付支持繁中、英文，数字和币种独立格式化。

## 7. 发布与可运维性

每个请求有 request_id，每次运行有 task_id、attempt_id、trace_id；错误可归类为用户输入、授权、配额、上游、执行和系统错误。指标不得以企业名和文件名作为无限基数标签。

数据库使用先扩展后收缩的迁移；同一大版本内设备协议兼容当前及前一个次版本。回滚应用不自动逆转不可逆数据迁移。每个发布需有依赖锁定、配置差异、备份恢复和灰度记录。

验证方法及实际结果分别见 [测试计划](../quality/01-test-and-acceptance-plan.md) 和 [文档审查](../quality/03-documentation-review.md)。本稿列出的运行指标目前均为待实施验证。

## 8. Admin Dashboard 非功能基线

另设后台负载集：100,000 个全局用户、1,000 家企业、1,000,000 条用量记录及同量级审计、5 名并发管理员，保留上述普通用户业务负载。设计目标为分页列表/详情 P95 ≤ 1s、指定范围聚合 P95 ≤ 3s；记录查询范围、索引、缓存、机器规格和冷热结果。这里的后台数据规模是新增验收条件，未做压测，不替代普通用户 800ms 目标。

列表默认每页 50、最大 100；超大查询、批量、导出进入独立队列，按管理员和付费主体限并发，不挤占用户执行、取消与鉴权。批量显式选择一次最多 100 项，更大筛选结果先建立服务端快照并分片；每片逐项检查当前权限和版本。导出文件默认 24 小时有效，凭据和正文不进入普通列表/导出，受限列另验权限，下载时再次检查。

平台管理员 MFA 是 M1 入口条件；敏感变更的风险阈值和审批者范围必须形成已发布策略，不能使用占位无限额。撤权在所有新请求、worker 领取/执行及下载重新核查；权限服务无法可靠确认时拒绝受影响操作。审计默认至少沿用本文件 365 天设计保留规则并受限访问，不代表已确认的法律期限。VIP 有效性按权威时间实时计算，后台调度停机不能延长有效期。

后台沿用 CopyPaste 浅深主题及繁中英文，密集表格使用无衬线正文和等宽数字。主体、金额单位、有效期、未知/待对账和权限受限有文字表达。错误摘要可聚焦并定位输入，列表返回保持筛选，提交超时复用 operation/幂等标识，键盘、200% 缩放和窄屏可完成普通开通流程。G10 与 TC-083–102 的运行指标、权限、并发及页面证据另行记录。
