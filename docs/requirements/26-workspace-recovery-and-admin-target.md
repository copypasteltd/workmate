# 26 · 首次建立恢复与Admin用户目标

补充原REQ-035/084及既有幂等、会话和用户管理要求，不替代完整验收范围。

1. 首次企业/项目创建在发送前保留同账户、同意图的原请求键与原输入。断线、超时、同一标签页刷新恢复时先读取原操作结果；未确认不得生成新键并重复创建企业、项目或钱包。
2. 回执按当前登录用户隔离，键本身不是凭据。重放和恢复必须复核当前用户、会员、企业状态和模式；删除/撤回/停用结果不重建。首项目失效允许恢复企业，使用当前可见项目。
3. 草稿在显式退出时移除企业/项目名称，保留无正文恢复标识。摘要、网络、刷新、导航等异步边界不能由旧账户续体写入新账户状态。
4. Admin从用户详情开费用/VIP，必须直接绑定明确用户ID。费用账户只能是该主体在当前模式下、当前管理员有权管理的账户。VIP主体只读且有效，不要求手拼ID。
5. 换详情用户清理旧弹窗、已填资料及费用/VIP预览。当前权限、MFA、策略、审批、确认、幂等和审计不放宽。
6. 用户目录的允许筛选参数写入URL，刷新、进入详情返回或浏览器返回可恢复。用户专属任务/内容需真正的用户筛选契约；未支持时不使用全量链接充当完成。
