# 網站／搜尋報告補充需求

本補充將原始營銷數據連接延伸到客戶可直接閱讀及下載的網站報告。原始 SRS、102 REQ／TC、專業角色與 G01–G10 驗收定義繼續有效；本增量不縮減既有要求。

GA4 流量／到達頁、GA4 事件及 Search Console 搜尋表現必須維持各自報告粒度。客戶可選已捕獲快照的一個帳戶、一個報告、範圍內日期與獲支持維度，取得摘要、分組及完整 HTML／CSV／JSON。完整下載不受畫面分頁截斷。每個數字須可由確切來源與計算規則重算，附來源及報告摘要；未知值、缺少來源行、零分母、非可加總用戶分開處理。退款允許負收入，不能讓其他非負指標繞過校驗。

Web 與 Desktop 提供雙語、明暗模式、可鍵盤操作的同一報告流程，延用 CopyPaste 設計色系。Desktop 維持原生無邊框、無 Electron 菜單及隱藏滾動條軌道，內容仍可捲動且不得橫向溢出。Desktop Agent 繼續本機 Codex；Extension 繼續原生右側欄的雲端對話與獲准附件上傳，透過既有公司 Web 入口閱讀完整報告。

營銷分析預設角色須以新版本 skill 使用同一確定性計算服務；不得讓模型自行猜測平台總量、用戶去重或不存在的轉換率。新角色版本不改寫歷史任務的角色／工具合約。報告計算本身不另外建立模型呼叫或收取 AI 費用。

Admin 的成員、項目、來源隔離、刪除、保留期限和權限管理須立即影響後續讀取及下載。已開啟頁面定期復核，拒絕時撤下舊數據與下載動作；讀檔期間撤權也不能完成輸出。斷開 OAuth 與刪除歷史資料是不同操作，沿用既有快照保留政策。
