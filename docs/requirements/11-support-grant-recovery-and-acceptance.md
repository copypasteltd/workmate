# 支持授权恢复及原始客服验收拆分

沿用 REQ-095：客服使用独立管理员身份和限时只读视图；客户授权不会赋予费用、VIP、写入、登录凭证或私人会话正文权限。原始需求及 TC-095 文字保持不变。

| 编号 | 细则 | 客户可见行为 |
| --- | --- | --- |
| SUP-REC-01 | 同一申请固定编号、明确范围及截止时间 | 网络异常重试不会建立第二份授权或延长原期限。 |
| SUP-REC-02 | 刷新先查收，绝不自动再次提交 | 已提交授权展示当前有效／撤销／到期状态。 |
| SUP-REC-03 | 未确认的申请不能被不同资料替换 | 页面提示先查收结果或使用原资料重试。 |
| SUP-REC-04 | 查收受当前本人和企业管理权限约束 | 其他账户或企业不能凭请求编号获取结果。 |
| SUP-REC-05 | 跨账户、企业及页面的迟到结果隔离 | 旧请求不能回填新范围的列表、正文或成功提示。 |
| SUP-REC-06 | 恢复记录最小化 | 客服原因、项目ID、正文及凭证不进入浏览器恢复记录；禁用存储时仅当前renderer内恢复。 |
| SUP-REC-07 | 原生端保持客户接口边界 | Desktop仅放行客户查收GET；Admin支持视图保持独立。 |
| SUP-REC-08 | 明确验收归属 | 原TC-095独立验收；REQ-055、094、签名安装和生产接入各自保留。 |
| SUP-REC-09 | 异常提示及放大布局保持可用 | 列表轮询不清掉表单错误；错误位置可见，200%放大后的设置／支持表单按可用宽度分栏。 |
