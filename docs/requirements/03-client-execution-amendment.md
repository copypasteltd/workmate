## 1. 用户原话

> Desktop 版本的内容，agent必须要在本地运行，并且允许客户向其提供 fully permission。要求最终的操作能力对标 codex desktop

> Extension版本的内容，核心内容应该是一个对标 chatgpt extension的样式和结构。但是承载了文件获取、读取并上传给云端的职能。

既有要求继续有效：Codex 为唯一内核；全部产品 AI 请求经公司内部 OpenAI 兼容服务；Desktop 无边框、无 Electron 默认菜单；扩展由工具栏打开浏览器原生右侧 Side Panel；品牌贴合 copypaste.hk；不调度本地 Docker/WSL；释放任务自建且不再使用的浏览器页面。

## 2. 当前生效的执行边界

| 入口 | Agent 执行位置 | 文件职责 | 交互主线 |
| --- | --- | --- | --- |
| Web | 公司云端 Codex | 用户上传的云文件及获准连接 | 企业云端 Agent 工作台 |
| Extension | 公司云端 Codex | 在浏览器获准获取、读取、上传本地文件，并绑定到本次消息 | ChatGPT 式对话、附件、连续追问；在原生右侧 Side Panel 中呈现 |
| Desktop | 客户本机 Codex 原生进程 | 在本机直接处理文件、工作目录和程序；选定资料可同步云端 | 本机 Agent 工作台，操作能力以 Codex Desktop 为对标 |

**本机运行 Agent 与本机运行模型是两件事。** Desktop 的会话执行循环、Codex 进程、文件工具和命令执行必须在客户电脑；推理和媒体 AI API 仍走公司内部服务器，不要求本机部署模型。

“ChatGPT extension”在本次按用户描述落实为对话式侧栏结构，并不宣称某个同名扩展是 OpenAI 官方产品；原 MetaMask 对标继续用于侧栏的出现方式，ChatGPT 对标用于侧栏内部交互。
