## 1. 用户原话

> Desktop 版本的内容，agent必须要在本地运行，并且允许客户向其提供 fully permission。要求最终的操作能力对标 codex desktop

> Extension版本的内容，核心内容应该是一个对标 chatgpt extension的样式和结构。但是承载了文件获取、读取并上传给云端的职能。

既有要求继续有效：Codex 为唯一内核；全部产品 AI 请求经公司内部 OpenAI 兼容服务；Desktop 无边框、无 Electron 默认菜单；扩展由工具栏打开浏览器原生右侧 Side Panel；品牌贴合 copypaste.hk；不调度本地 Docker/WSL；释放任务自建且不再使用的浏览器页面。

## 2. 当前生效的执行边界

| 入口 | Agent 执行位置 | 文件职责 | 交互主线 |
| --- | --- | --- | --- |
| Web | 公司云端 Codex | 用户上传的云文件及获准连接 | 企业云端 Agent 工作台 |
| Extension | 公司云端 Codex | 在浏览器获准获取、读取、上传本地文件，并绑定到本次消息 | ChatGPT 式对话、附件、连续追问；在原生右侧 Side Panel 中呈现 |
| Desktop | 客户本机 Codex 原生进程 | 在本机直接处理文件、工作目录和程序；选定资料可同步云端 | 本机 Agent 工作台，操作能力以 Codex Desktop 为对标 |

**本机运行 Agent 与本机运行模型是两件事。** Desktop 的会话执行循环、Codex 进程、文件工具和命令执行必须在客户电脑；推理和媒体 AI API 仍走公司内部服务器，不要求本机部署模型。

“ChatGPT extension”在本次按用户描述落实为对话式侧栏结构，并不宣称某个同名扩展是 OpenAI 官方产品；原 MetaMask 对标继续用于侧栏的出现方式，ChatGPT 对标用于侧栏内部交互。

## 3. Desktop 必须满足

| 补充验收编号 | 必须观察到的行为 | 关联既有需求 |
| --- | --- | --- |
| DESK-L01 | 打包程序在客户机启动锁定版本的 Codex app-server；记录本机进程身份、版本及会话映射，实际完成一轮本机工具调用 | REQ-039、044、075 |
| DESK-L02 | 本机执行会话使用本机工作目录；能够读取、创建、修改文件，执行终端命令，运行开发/设计工具并交付真实结果 | REQ-039、040、078 |
| DESK-L03 | 用户可在本机界面主动选择并授予“完整本机权限”；授权后 Codex 能操作当前 OS 用户有权访问的本机资源，不限于旧桥接器的一小时目录和仅新建文件能力 | REQ-039、040 |
| DESK-L04 | 完整权限的实际配置与界面一致，既不暗中保持 read-only / 禁 shell，也不在已获完整授权的范围内逐命令重复要求确认；用户可以撤回或降级 | REQ-040、044 |
| DESK-L05 | 本机展示流式消息、命令输出、文件变更、等待输入和费用；能够停止本任务进程并从受支持检查点恢复，不自动转为云端执行 | REQ-009、039、041 |
| DESK-L06 | 角色预设及 Skill 在本机 Codex 实际加载，并在本机调用相应工具；内部模型和媒体服务仍使用公司网关 | REQ-043、044、075、078 |
| DESK-L07 | 登录、企业/项目权限和费用由平台管理；本机完整授权只能由本机用户作出，平台 Admin 或扩展不能代为开启 | REQ-039、043、100、102 |
| DESK-L08 | 本地会话和执行归属可恢复；切换账户、撤销、退出及更新正确处理本机运行，取消只终止本任务拥有的进程/页面 | REQ-039、041、042、050 |

“完整本机权限”对应当前 OS 用户权限，不自动获得管理员/root，也不代表离线本机模型。项目范围限制仍适用于平台上的企业资料与账单；不能把这种服务端限制解释成只允许 Desktop 访问一个本机目录。只读/工作目录模式可作为产品默认，完整权限是必须提供的实际能力。

对标 Codex Desktop 是能力目标：本机文件、终端、工具、Skill、持续会话及执行控制。浏览器/应用操作通过相应的本机工具集成逐项交付和验证，不能仅凭装入 Codex 就宣称所有系统应用都已支持。

| EXT-C04 | 在同一会话持续提问，接收云端 Codex 的流式回复、工具进度和成果；扩展关闭/worker 休眠后可恢复云端会话 | REQ-009、036、041 |

预算、连接器、目录和业务工作台可保留为折叠设置或完整 Web 入口，不能让用户先填完整任务表单才能发送普通消息。品牌与信息密度沿用 CopyPaste，结构参考不要求复制其他产品商标。
