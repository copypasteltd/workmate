# 广告预算操作补充需求

本补充将优先营销业务中的 Google Ads 数据分析接到一项受控执行能力：非共享标准平均每日预算修改。项目级策略默认关闭；客户管理者须明确设置账户、预算白名单、币种、平均每日上限、单次差额、期限和确认方式。默认逐次确认，范围内自动执行需要客户显式授权。

完整使用流为登录 → 企业／项目 → OAuth → 广告主账户及项目绑定 → 策略 → 现值读取及冻结预览 → 确切操作 → 客户确认或明确范围内排队 → 执行前重查 → 原请求和回执。修改输入必须重新预览。模型不具备自行确认或修改策略的工具。重复提交、并发 worker、权限撤回、策略更新、连接重绑、远端漂移及失联均须有明确状态和可核对证据。

外部结果未知时不可重试修改；人工可以读取现值并记录核对／关闭，但不能据现值倒推原请求成功。收到原始回执后本地加密留存，数据库故障恢复不得再次发送。Google 远端无 CAS 的竞争窗口以及已准入请求不能撤回的边界必须在方案中准确说明。

Web 与 Desktop 提供双语完整面板。Desktop 维持本机 Codex、客户可授予完整权限、无边框、无 Electron 自带菜单、隐藏上下滚动条且无横向溢出。Extension 维持原生右侧栏及云端 Agent，完整策略管理由公司 Web 页面承载。Admin 按企业／项目查看与管理策略、操作及回执；读取、策略修改和异常处理是独立权限，有当前 MFA、显式 deny 及审计，不能冒充客户确认。历史角色不可自动扩大。

验收使用用户允许的假账户和假模型，必须区分实际应用／本机 Codex 的执行证据与真实广告投放效果。原需求矩阵和完整产品门槛继续有效。
