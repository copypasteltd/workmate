# Desktop 本机 Agent、客户完整授权与费用通道

此前 Desktop 的主页面仍提交云端任务，本机只提供独立监督器及文件桥，未落实 CLIENT01。现在默认进入本机 Agent 工作台：客户选角色和目录，在系统对话框确认权限后，本机 Codex 实际处理文件和终端；模型请求继续走公司内部服务器。

## 客户可见变化

- 保留无边框、自绘标题栏及无 Electron 默认/Alt 菜单；新增本机会话、消息、操作记录、预算、停止和公司费用记录。
- 选目录本身不授予执行权限。可选择唯读、目录内读写或完整本机权限；完整权限默认取消，授权后不逐命令重复审批，可访问当前 OS 用户有权操作的工作目录外资源。空闲时可降级，随时可撤权，登出即撤销。
- 同一会话的后续消息恢复同一本机 Codex 线程；每轮取得新的任务级凭据和单独费用预留。
- 网络中断时，停止/撤权使用本地登录归属先关闭自有运行时；公司回执另行同步。创建或启动响应丢失后可取消待处理工作，沿用原始请求，不重跑本机动作。
- Desktop 原生登录不能从旧 API 静默入队云端 Agent。需要云端工具时明确在浏览器打开 Web；未支持本机工具的角色不会被替换为云端执行。
- Extension 保持原生右侧栏的云端对话及文件上传，不因本机 Agent 改动变成本机任意命令客户端。

## 代码和账务

迁移 092 新增不可变执行位置及设备/账号/登录 family/会话/目录摘要/运行时绑定。本机任务不产生云队列 outbox；云端容量入口、Worker、恢复及数据库触发器共同限制执行位置。本机与云端复用角色/Skill、固定能力和费率、容量、预留及账本。

主进程拥有加密会话日志、原生确认、稳定请求键和原生进程。渲染页面不能取得模型凭据、二进制路径或调用原生执行 API；编码路径别名也被拒绝。原生 shell 不继承推理凭据。随包固定 `0.163.0-alpha.11` Windows x64 Codex 与辅助程序，不使用 PATH 或其他内核回退。

服务端逐次推理重验身份/项目/权益/版本/来源/租约和预算。完成先封锁准入，再关闭上游并结算；只接受公司观测的 usage，不接受客户端自报费用。创建或结算响应丢失沿用原请求；已接受本机动作不盲目重跑。未知结果、过期租约或缺少供应商 usage 保留待核对预留。

## 验证与范围

[检查点](../quality/desktop-local-execution-checkpoint.json) 绑定实际源码、测试、打包程序摘要、四张页面、MP4/GIF 和自有进程/浏览器/原生数据库清理。真实 Codex、Electron、邮箱/PKCE、文件、原生沙箱、公司控制面和账本实际执行；模型响应、选目录和系统授权决定是明确测试夹具。

首批本机准入 fullstack、frontend、backend-api、software-qa、landing-page。全部 18 角色、29 Skill、本机媒体/设计/营销及应用/浏览器工具仍按原需求推进；人工系统对话框操作、生产模型、签名、安装/升级/卸载及完整 OS 矩阵仍待验收。原 102 REQ、102 TC、NFR、G01–G10 保持，未提升为完整产品验收。

原始失败和此前完整平台、扩展及旧文件桥媒体保留原字节与源码范围。开发、脚本和候选产物在唯一 D 盘 `dev/`；主文档在 `docs/`；禁止本地 Docker/WSL/虚拟化，释放自建且不用的浏览器页面。

发布清单明确记录 Desktop 测试文件由 Git 声明的 CRLF→LF 换行转换，分别绑定验收原文件与提交 blob 摘要；原始源码档案和测试证据不改写。
