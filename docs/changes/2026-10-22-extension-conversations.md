# Extension 对话与附件更新

Chrome 原生右侧栏以连续对话为主，提供新会话、历史、底部输入框、选取/拖入附件、主动添加网页、预算设置和停止。通知、账户及原独立任务表单收进折叠区域。浏览器读取获选文件并上传公司云端；付费消息引用上传成功的明确文件版本，云端 Codex 执行。

发送回执绑定用户/企业/项目。网络中断及侧栏重新打开时沿用原消息、文件版本、预算和幂等键，避免重复任务与预算预留；当前来源失效会清空旧回复并阻止继续发送。全部 AI 继续使用公司内部网关。

验证：32 项扩展测试、类型/构建检查和 7 项真实 Chrome 原生右侧栏旅程检查。旅程使用真实身份、API、上传、数据库、Worker 和账本，模型回合明确模拟。截图、MP4、GIF 和源码摘要见 [检查点](../quality/extension-chat-checkpoint.json)。旧失败记录保持原字节。

Desktop 独立本机 Codex 模块仍需接入本人授权界面、费用凭证和安装包。全部产品需求及完整验收门槛继续有效。使用及细节见 [技术说明](../technical/71-extension-cloud-conversations.md)。
