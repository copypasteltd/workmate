# Desktop 本机用户追问

Desktop 接通真实本机 Codex 的用户追问：对话内展示未预选的问题，支持选择及自填答案，刷新页面后继续同一个等待；回答继续原任务、原线程和原回合，沿用原预算。等待时仍能停止或撤销完整权限，旧回答、重复提交、错绑账号及无效答案被拒绝。

问题和回答仅作为主进程临时交互状态，不直接写入产品会话日志或账单；答案仍会进入本机 Codex 和公司模型上下文。卡片沿用现有品牌与双语界面，支持键盘和最小窗口内滚动。

验证范围、实际截图/录屏与前两次失败探测见 [源码检查点](../quality/desktop-native-input-checkpoint.json)，实现和流程见 [技术方案](../technical/74-desktop-native-user-input.md)。后端沿用源码未变的阶段 73 完整回归；当前 Desktop 另有新的原生和实际打包验证。供应商响应和系统窗口决定继续明确模拟。

Desktop 始终在客户本机执行；Extension 始终使用原生右侧栏获取用户获选附件并调用云端 Codex。16 个本机角色的协议接通不等于完整专业业务验收，18 角色/29 Skill 及全部原始需求继续保留。
