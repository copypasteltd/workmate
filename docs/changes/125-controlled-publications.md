# 阶段125更新 / Stage125 changes

客户现在可以在获授权账户和项目中预览实际营销素材，并逐次明确确认发布；未知结果保留原副作用身份，只读核对或人工结案，不自动重发。独立Admin可按项目审阅、配置策略与处理未发送/未知操作；正文读取权限独立。Desktop继续使用客户本机Codex，Extension继续使用原生右侧栏及受限Web交接。

Customers can review actual outgoing media and explicitly approve each publication. Unknown results preserve the original effect identity and are reconciled without automatic replay. Scoped Admin controls keep private-body access independent. Desktop remains customer-local Codex; Extension remains a native right Side Panel with fixed scoped Web handoff.
