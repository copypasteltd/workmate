# Desktop 父子流程恢复与收尾 / Desktop workflow recovery and shutdown

本轮补齐主任务与工作流子任务在后台授权保活响应卡住时的取消与正常收尾，并实际验证两个子任务在轮次前发生启动故障后的安全恢复。客户电脑运行固定 Codex，公司服务管理当前权限、模型网关和原任务费用。

This increment fixes parent/child shutdown and normal completion while a background authority response is withheld. Actual child startup failures recover before turn admission. Pinned Codex runs on the customer's computer; company services retain current authority, inference and original accounting.
