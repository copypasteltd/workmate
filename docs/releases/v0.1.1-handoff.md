## 获取源码与启动 / Source and launch

完整包包含七个分发ZIP。将 `buildable-sources.zip` 与 `source-runtime-windows-x64.zip` 合并解压至同一个源码根目录，然后按 [使用说明](v0.1.1.md#本机首次使用--first-local-run) 选择空闲原生数据库端口，从Delivery执行 `demo:preflight` → `bootstrap:demo` → `demo:check` → `demo`。Web为4317，Admin为4318；邮箱验证码、Admin独立开户/TOTP、Desktop配对和扩展安装步骤均在使用说明中。退出使用Delivery的 `npm run stop`。

The bundle contains seven distributions. Merge buildable sources and the pinned runtime into one source root. Follow the guide to select an unused native database port, then run the Delivery preflight, bootstrap, check and demo commands. The guide covers customer OTP, separate Admin enrollment/TOTP, Desktop pairing and Side Panel installation. Stop owned services with Delivery's `npm run stop`.
