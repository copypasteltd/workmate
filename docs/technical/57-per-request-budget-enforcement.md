## 共同预算

客户文本与图片调用必须共用任务原预留，不能分别累计后在最终结算时才发现超额。每笔文本调用先计数完整实际上下文，随后用冻结输入/输出单价和明确输出上限计算承诺；图片按冻结单张价格承诺。预算事务原子比较已确认精确费用、尚未使用的承诺和未知在途，不再次预留客户钱包。所有计算保留百万分之一 micro 的精确分子，合计后统一取整。

输入计数使用公司内部 `POST /v1/responses/input_tokens`，包括实际输入、指令、工具、推理及输出格式等计数参数。计数与随后生成的操作 ID、完整请求摘要、原主体和冻结能力绑定，一份计数不能用于其他请求或再次生成。缺少接口、计费策略或有效计数时，不能猜测 token 数继续付费生成。模型别名、推理强度及输出上限不因预算不足而自动替换或降低。

计数是实际公司 API 请求，单独保留请求、发出、终止、费用与未知状态，并纳入阶段 56 相同的并发和速率。计数服务费用由平台承担；不能假定接口免费，也不能计入客户账单。平台只有在明确配置验证状态和单次计数费后才可调用。后台能力验证使用自己的运行预算与平台每日预算，不能使用客户钱包；其计数费用也纳入该验证预算。

```mermaid
flowchart LR
  Request[实际规范化请求] --> Count[平台预算 / 内部精确计数]
  Count --> Proof[操作 ID / 摘要 / 主体 / 计数证明]
  Proof --> Allocate[冻结价格与输出上限 / 原子分配]
  Allocate --> Recheck[当前身份与任务权限]
  Recheck --> Generate[内部生成或编辑]
  Generate --> Facts[真实终止与费用事实]
  Facts --> Settle[聚合分子 / 唯一最终结算]
  Generate --> Unknown[未知 / 保留承诺与容量]
```

## 异常与历史记录

未发出取消或拒绝才可确认为零。未知调用保留原承诺并阻止该主体的新调用；没有证据时不能把未知费用归零。实际输入数与计数不同、输出超出上限或费用超出承诺时，先保留供应商真实用量和费用，再记录预算违约并进入核对，不能回滚已经发生的消费事实，也不能自动扩大客户已批准的预算。

最终账本以持久调用事实为依据，避免“终止帧被阻断但已发生费用”的消费丢失；文本与图片不能通过工具记录再重复扣款。平台计数与验证费用独立于客户账本。明确标识的模拟适配器和独立探针不作为真实业务计费接入的证明。

升级不补造历史调用或历史消费。可从尚未执行、存在原预留的排队/暂停任务建立原预算边界；历史在途且缺少预算证明的主体须核对，不能凭空视作未消费。原表原有字段、旧 SQL 与校验值、历史运行报告及失败前源码均须保留。

完整后台预算策略发布、独立审批、请求目录、费用与容量分别核对的管理界面仍属原目标中的必需工作。开发配置和数据库夹具不能代替该管理功能。

## 管理端后续验收约束

- 策略面板需展示并发、速率、运行预算、每日平台预算、计数验证状态和明确费率的当前版本与历史版本。发布须复用当前 Admin 权限、MFA、原因、精确版本预览和独立审批；重新检查原操作人和审批人的当前权限。提高策略不能扩大客户已经批准的任务预留。
- 请求目录需支持任务/能力验证、文本/图片/输入计数、数据模式、企业、原用户、项目、能力版本和结果筛选。详情关联原请求、计数证明、冻结费率、预算分配、真实用量、已知费用及未知承诺；不得泄露提示词、服务器密钥、私有执行 nonce 或其他企业内容。
- 费用核对与容量释放须作为不同操作处理。每次变更绑定可检查的供应商终止/账单证据、影响范围、操作者、审批、幂等键和审计记录；不能通过取消按钮把未知改为免费，也不能把释放容量当成费用已确认。
- 平台计数和后台验证费用必须与客户钱包、赠款、VIP、授信及人工费用调整分开归属。列表、导出和用户消费详情应说明已知部分与未知部分；不同调用的逐笔取整不得再次汇总为客户最终账单。
- 当前每日额度按 UTC 日建立不可变边界；同日降低配置立即约束后续分配，提高配置不会自动扩展原日边界。管理端后续发布设计必须明确生效时间及审批后的边界变更，不得静默重置已用额度。

完整计数只接受已覆盖的上下文参数；不能省略未知上下文字段后继续调用。固定 Codex 版本的 `client_metadata` 属于传输信息，按生成参数保留，计数正文仍包括实际输入、工具、指令和格式。当前存储提示词引用等未覆盖字段会在计数与生成前拒绝；不会猜测其内容。

[官方输入计数指南](https://developers.openai.com/api/docs/guides/token-counting)与[参数参考](https://developers.openai.com/api/reference/typescript/resources/responses/subresources/input_tokens/methods/count)用于核对协议，未据此假定公司计数服务免费。联调继续使用获准假数据，Codex、原生数据库、鉴权和预算事务实际执行。
