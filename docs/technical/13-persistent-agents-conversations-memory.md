## 数据与授权

Agent 实例引用已安装角色及精确版本，定制仅能缩小工具集合、修改职责和品牌范围，不能换内核、模型路径或注入可执行 Skill。更新以 expected_version 创建不可变版本；历史任务固定该版本。普通停用阻止新任务，内容隔离阻止运行中的后续工具。

Conversation 归属项目及创建用户，普通企业管理员不会因项目权限看到其他成员私有会话。任务和派生产物继承私有归属；数据库额外限制 private_owner，API、下载、版本和模型工具均使用当前用户上下文。用户可明确把产物复制到共享项目，复制不携带私有对话或记忆。平台 Admin 仅在相应范围的正文权限下查看和治理。

记忆支持企业、品牌、项目、会话和个人作用范围，版本与到期时间明确。企业/项目共享记忆由项目管理者维护；个人和会话记忆由所属用户维护。任务只保存固定引用，不把正文再复制到任务 prompt；删除清空可读取正文并使引用失效，后续模型调用与工具拒绝失效上下文。

## 执行一致性

用户消息以 conversation_id + client_message_id 去重，同一事务保存消息、任务、有效配置引用、预算预留和 outbox。并发委派每会话只允许一个未结束任务，未知费用仍算在途。归档不取消任务；删除有在途任务时返回 ACTIVE_TASKS。版本冲突不静默覆盖。

任务执行前组装获准的历史消息、固定 AgentVersion 与记忆版本；历史和内容长度设上限，超限要求明确拆分，不静默截断。上下文内容始终是数据，不能扩张注册工具。新的 Codex 进程仅使用当前任务授权上下文，不自动复用包含已撤销资料的旧原生 thread。

execute、ask、plan 在服务端限制工具；ask/plan 不生成媒体或写业务文件。计划输出需绑定输入摘要与版本；批准前重新检查当前 Agent、记忆、任务版本和预算，不复用过时批准。用户后续委派才能扩大操作模式。

## 验证要求

使用真实 PostgreSQL 验证：跨用户/企业私有资源不可见、ID 猜测及私有产物引用拒绝、版本冻结/CAS、去重与并发预留、归档/删除边界、记忆范围/到期/删除、受限模式、过期计划和 Admin 正文/隔离权限。浏览器以真实邮箱登录贯穿专家创建、会话、记忆与删除，并保存实际截图；Desktop 显式同步快照并重新构建。公司真实 AI 资格仍需真实凭证，受控测试不替代它。

## 实际代码与接口

独立 platform 的 `src/persistent-work.ts` 负责专家/会话/记忆与计划批准；`task-service.ts` 统一受理、权限/角色能力/套餐、预算预留与 outbox。`worker.ts` 在启动、心跳、工具及最终提交重验上下文。`storage.ts` 根据当前任务派生 private_owner；`assets.ts` 的 publish 只复制本人私密成果到项目。`admin-content.ts` 实施有范围的正文治理与清空。

以下路径均在 `/v1/tenants/:tenant/projects/:project` 下，使用普通用户身份、项目权限与私有归属：

| 路径 | 操作与一致性 |
| --- | --- |
| `/agents`、`/agents/:id` | 列表/创建/修改；严格字段、已安装角色、工具子集、expected_version |
| `/agents/:id/versions` | 只读不可变版本历史，固定角色哈希 |
| `/conversations`、`/conversations/:id` | 所属用户列表/检索/创建/读取/置顶/归档/版本采纳/删除 |
| `/conversations/:id/messages` | client_message_id 去重、expected_version、笔记或委派、单在途任务、同事务预留 |
| `/memories`、`/memories/:id` | 五种范围、管理者/所有者限制、版本/到期、清空和墓碑 |
| `/tasks/:id/plan`、`/tasks/:id/plan/approve` | 只读计划；输入摘要/计划与任务版本、当前范围、预算、一次执行 |
| `/assets/:id/publish` | 所有者明确确认，版本检查，新共享副本，不公开原私密文件 |

新增 005–007 迁移创建不可变版本、任务私有归属、单会话在途唯一约束、父资源 RLS、删除期受控事务开关及幂等墓碑；已应用迁移不改写，后续变更新增迁移。迁移执行器统一记录成功版本，避免旧迁移遗漏登记后重复执行。

当前历史最多 80 条、适用记忆最多 50 条，获准上下文 JSON 总长最多 60,000 字符；超限明确拒绝。列表为有界集合，不宣称无限历史与分页云目录。已受理任务保持固定版本；计划转执行则要求当前版本与摘要一致。公司模型尚未联调时不允许委派，但专家配置、笔记与记忆管理可独立使用。

## 删除与后续工作

会话删除清空消息、任务正文、事件、计划、关联私密记忆版本和可重放响应，私密产物转不可读；账务及审计保留必要引用。用户已明确发布的共享副本不被隐式删除。幂等唯一键保留墓碑，旧请求不会再次创建内容。

物理对象与 Codex 运行缓存回收、完整暂停检查点、团队并行、云定时计划、SSE、协同编辑和真正生产隔离仍属于后续实现。本轮测试覆盖限定的数据/授权/状态约束，不替代全部 102 项综合验收。
