# 網站報告自適應排版

網站分析最初沿用 580px 通用對話框，但指標列按照整個視窗寬度選擇三列，造成長百分比及加權排名在卡片內折行。這次將網站報告對話框的最大寬度設為 1000px，指標卡片改由自身容器的可用寬度分配列數，理想最小寬度 240px；不足一張卡片寬度時採用容器寬度。

保持完整小數精度、原有雙語／明暗模式、全部數據與授權流程。Desktop 仍可縱向捲動，維持無邊框、無原生菜單、隱藏滾動條軌道及禁止橫向溢出。沒有使用隱藏數字、截斷數據或全局禁止捲動來掩蓋排版問題。

實際 Web 1440px／375px、Desktop 1440px／800px 與 800px 中文深色狀態逐一量測每個指標的文字行框、文字寬度及可用寬度。每個捕獲數值必須只有一行且不超出卡片。原本網站分析的 11 條流程同時重走，包括登入、OAuth、下載、未知日期、網址型 Search Console 屬性及來源撤回。

這次只有 Web CSS、Desktop 對應 CSS 與 renderer 摘要改動；後端、原生 Codex、權限與計費代碼沿用上一輪通過的 195 項局部檢查，未宣稱重跑或完成全產品驗收。新證據包含實際未簽名 Desktop 打包版，第三方帳戶及模型仍為假資料。
