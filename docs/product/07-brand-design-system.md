# CopyPaste 品牌与产品设计规范

版本：1.3 · 2026-10-18 · 来源：BRAND01，用户要求最终产品风格、样式及色系贴合 [CopyPaste 官网](https://copypaste.hk/)。本规范替换旧交互文档的通用配色默认；适用于 Web、Chrome 扩展、Desktop 及产品管理页面。

## 1. 设计依据与目标

官网呈现暖灰白底、深墨文字、少量亮蓝强调、白色细边卡片、圆角和轻阴影；大标题使用衬线体系，正文和操作使用无衬线，主要按钮为深墨底浅色字，导航/按钮呈胶囊形。深色模式使用深蓝黑背景、浅灰蓝文字及较浅蓝强调。保留这些特征，使官网与 Agent 产品能够被识别为同一品牌。

官网是企业服务展示站，产品是持续工作的 Agent 工作台。产品沿用品牌色、字体层级、图标及组件语言，按任务密度收紧留白。主路径仍为目标输入、专业角色、会话执行和成果修改；首页可体现官网的气质，会话、代码、报告和视频编辑保持稳定可读。

依据为 2026-10-18 实际读取的官网 HTML/CSS/脚本及原生浏览器浅色、深色和移动视图。详见 [品牌核查记录](../research/03-copypaste-brand-reference.md)及 [取样数据](../research/copypaste-brand/source-evidence.json)。其中精确色值为官网来源；新增状态色、布局密度、字号与无障碍增强标为产品设计扩展。

## 2. 品牌色与语义映射

以下均直接对应官网 CSS 变量，两套主题一起定义。界面通过语义 token 使用，不在页面中另建独立品牌色。

| 官网变量 / 产品语义 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| primary / 品牌主色 | `#0E1726` | `#D8DEEA` | 品牌和重点内容，保留官网定义 |
| secondary / 次级品牌色 | `#202D45` | `#B5C1D8` | 辅助层级 |
| accent / 强调色 | `#1F5EFF` | `#79A2FF` | 链接、选中标记、焦点、真实执行进展 |
| bg / 页面背景 | `#F6F6F4` | `#0F131A` | 产品工作区底色 |
| bg-soft / 次级背景 | `#EFEFEB` | `#141A24` | 侧栏分区、输入辅助区和低对比底层 |
| surface / 内容表面 | `#FFFFFF` | `#171D29` | 会话、角色卡、表格、弹层 |
| text / 正文 | `#15171A` | `#E8EDF8` | 标题、正文与主操作 |
| text-muted / 辅助文字 | `#5D636D` | `#A0ACC2` | 说明、时间、次要信息 |
| border / 装饰边界 | `#D8D9DE` | `#2A3344` | 卡片/区块分隔；必要控件边界另用增强 token |

主按钮使用 `text` 作填充、`bg` 作文字，呼应官网的深墨主 CTA；次按钮使用 surface、text 和边框；蓝色用于重点标记及链接。正文、输入和大面积表面保持中性色。浅/深主题切换只影响产品界面，不改变图片、视频、代码或客户交付文件的内容。

官网的 border 用于轻量装饰，不单独作为输入框、复选框、焦点或图表的必要识别边界。产品增加 `control-border`（浅 `#858B95` / 深 `#68758D`）、完整焦点环和状态文字，以满足必要对比。状态色和图表分类色属于产品语义扩展，不能替代品牌强调色。

权威 token 记录在 [brand-tokens.json](../design/brand-tokens.json)，配套 [CSS 变量](../design/brand-tokens.css)和[可切换主题的视觉样板](../design/brand-preview.html)。它们是设计交付，不代表完整产品已实现。

## 3. 字体与文字层级

官网正文声明 Manrope/Avenir Next/Segoe UI 等无衬线，标题声明 Fraunces/Iowan Old Style/中文衬线。本次 Windows 实际渲染回退到 Noto Sans SC、Noto Serif SC 与 Segoe UI，声明字体与实际可用字体分别登记，不能声称已下载了 Manrope/Fraunces。

产品保留「衬线展示标题＋无衬线操作正文」层级，为香港用户增加繁中 TC 字体。生产应固定字体来源、许可、文件版本和覆盖测试；字体从受控产品资源加载或使用明确的系统回退，不能依赖未登记的第三方字体请求。

| 角色 | 设计约定 | 典型用途 |
| --- | --- | --- |
| display | Fraunces / Iowan Old Style；繁中 Noto Serif TC / Source Han Serif TC / Songti TC / PMingLiU；600，32–48px（窄屏可 30px），行高 1.2 | 新工作页主标题、品牌引导与重要空状态 |
| heading | 无衬线 600–700，20–24px，行高 1.3；展示型角色/方案标题可用衬线 | 会话标题、页面分区、弹层 |
| body | Manrope / Avenir Next / Segoe UI；繁中 Noto Sans TC / PingFang TC / Microsoft JhengHei；默认 16px，行高 1.65 | 解释、会话和报告正文 |
| compact | 同正文，14px，行高 1.5；标签 600，说明不小于 12px | 侧栏、表格、操作、时间和属性 |
| data/code | Cascadia Code / SFMono-Regular / Consolas，13–14px；金额/报表启用等宽数字 | 代码、ID、费用和数字对齐 |

英文短标签可沿用官网的字距与小型大写风格，长中文正文保持正常字距。价格、日期、百分比和费用要可读；Logo、按钮、状态和正文不使用艺术字图像替代真实文字。

## 4. Logo、图标与品牌元素

使用官网现有浅/深 Logo 资源，保持原比例与形状；原始资源取样位于 [品牌资料目录](../research/copypaste-brand/source-evidence.json)。浅色使用 CopyPaste_Light，深色使用 CopyPaste_Dark，取样与实际渲染选择一致。应用入口配「CopyPaste Agent」产品工作名，公司法定名称用于登录/管理等合适位置。

Logo 在工作台建议 32–40px，保留至少图标宽度四分之一净空；官网 42px、12px 圆角容器可缩放继承。不得用新生成图标、重绘标志、彩色角色头像或字符图案替代公司标志。品牌素材生产的客户 Logo 单独管理。

工具和角色图标统一使用一套线性 SVG，通常 18–20px、1.5–2px 线宽，配真实文本名称；选中态用品牌蓝的小面积标记。各角色通过图标、名称和职责区分，不给十八个角色分配大面积不同主题色。

官网的淡网格、节点和轨道可转化为新工作空状态中的轻量静态背景或任务依赖示意，节点必须表达真实对象关系。执行区域以明确步骤和状态为主，持续装饰动画会影响长时间工作。

## 5. 组件语言

| 组件 | 品牌与交互约定 |
| --- | --- |
| 主按钮 | 44px 最小主要点击高度，深墨/浅字，深色反转；pill 999px 圆角，文字与动作一致 |
| 次按钮/筛选 | 中性 surface、text、细边框；筛选选中用品牌蓝标记与文字/形状变化 |
| 卡片/面板 | 内容卡 16px 圆角、1px 装饰边、20px 内距；紧凑卡可 14px，重点输入/成果容器可 26px |
| 阴影 | 浅色继承 `0 12px 28px rgba(12,21,35,.08)`；深色继承 `0 14px 34px rgba(0,0,0,.32)`；浮层优先使用，密集列表依边界组织 |
| 目标输入框 | surface 背景、增强控件边界、明显焦点；附件/角色/模式与发送动作有独立标签和禁用原因 |
| 侧栏/导航 | bg/bg-soft 与克制 surface 层次，当前项有文字、底色及蓝色线/点；企业/项目上下文持续可见 |
| 会话/工具步骤 | 留白和弱边框分组，真实步骤/费用/依赖可展开；不把整条回复涂成高饱和品牌色 |
| 角色卡 | 图标、专业名称、职责、可交付类型、可用性和「使用」；筛选、焦点、待接入与禁用态完整 |
| 成果/文件 | 中性预览底、版本/格式/大小/审阅状态；客户图片和视频保持原色，选择区域使用可辨轮廓 |
| 表格/图表 | 中性底色、等宽数字、蓝色重点与语义分类色；行选中有非颜色提示，图表有图例/表格和数据来源 |
| 提示/状态 | 成功、错误、等待、运行、部分成功分别有图标＋文字；新增色值在 token 中标为产品扩展 |
| 弹层/抽屉 | surface、圆角、阴影；焦点进入/返回、键盘关闭和后台不可操作行为明确 |

官网按钮 hover 的轻微抬升可以用于独立 CTA 和角色卡；密集工作区使用边框/底色变化，避免表格和文件列表位移。过渡沿用 160/180/220ms；布局切换保持状态，尊重 reduced-motion，停止无实际意义的循环动画。

| 页面/端 | 具体应用 |
| --- | --- |
| P01 登录/邀请 | 公司 Logo、衬线标题、暖灰白底、单一 surface 表单；保留错误/邀请状态 |
| P02 新工作 | 官网式衬线主标题、克制蓝色标记、重点目标输入、专业角色及示例工作；不堆叠宣传区块 |
| P04 会话工作台 | 品牌侧栏＋沟通/成果双栏，顶部紧凑无衬线标题，浮层和输入沿用同一 token |
| P05/P06 素材与视频 | 工具栏继承平台样式，画布/视频忠实呈现客户素材；深浅主题不改客户作品 |
| P08 分析报告 | 背景/表格/图表/证据抽屉统一，数字与公式优先；品牌色仅突出重点 |
| P15/P16 角色和能力 | 18 个目录使用一致卡片，开发/设计/分析/流程共享同一视觉体系；状态与安装/绑定区分 |
| P09/P10/P11/P12/P13/P14/P17/P18 | 文件、设备、流程、费用、管理、项目和通知共享组件及状态语言，不另起后台主题 |

产品扩展的布局基线：桌面顶栏约 64px、侧栏约 240px，内容间距使用 4/8/12/16/20/24/32/40/48px。完整双栏建议在 ≥1280px 使用；768–1279px 可折叠侧栏并切换成果标签；窄屏单栏，375px 仍可执行核心流程，弹出导航不得挤坏输入框。官网展示容器 1140px 可作为登录/引导页参考，工作台根据有效空间扩展。

## 7. 主题、可访问与客户品牌边界

浅色为默认设计，深色使用官网现有完整色组；提供浅/深/跟随系统的偏好，切换不重建会话或改变任务/成果版本。首次绘制使用一致主题，避免亮暗闪烁；偏好作为用户/本端设置，不改变企业业务配置。

正文与背景按既有 AA 设计目标检查 4.5:1，大字及必要非文字控件按 3:1；焦点清晰可见，hover、selected、disabled、error、loading 和键盘路径均需验证。Token 的静态数值核查只验证列出的组合，不代表整站无障碍符合性认证。

平台界面使用 CopyPaste 品牌；客户的广告、演示、网页与其他交付使用客户自己的品牌版本或该次 brief。设计师/品牌等角色的 Skill 必须区分 `platform_theme` 与 `customer_brand_version`。预览背景和平台操作按钮可以继承 CopyPaste，导出的作品不自动带上平台蓝色、字体、标志或水印。

## 8. 设计交付与验收

新增 REQ-081/082、TC-081/082，来源 BRAND01。设计交付包括本规范、官网取样和截图、JSON/CSS token、浅深主题视觉样板及前端实施约定。后续实际组件和页面按 P01/P02/P04/P05/P08/P15/P16、扩展及 Desktop 代表视图验收。

验收清单包括官网基础色精确一致、品牌 Logo、字体层级和繁英覆盖、按钮/卡片/边框/阴影、跨端复用、浅深状态、键盘/缩放/对比及客户作品不被平台主题污染。至少覆盖 375/768/1024/1440px、100%/200% 缩放和 reduced-motion；浏览器创建的不用页面和上下文在成功、异常、取消后回收。

官网来源的更新需要重新取样、评审 token 影响并形成新版本，不能在产品运行时直接加载官网 CSS。禁止在独立页面中恢复旧默认 `#2563EB/#F8FAFC/#1E293B` 作为产品主题。当前样板用于核查视觉方向，完整产品验收仍为 not_run。
