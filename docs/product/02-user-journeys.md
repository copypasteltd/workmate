# 用户旅程与业务流程

版本：1.5 · 2026-10-18。页面标识见 [交互规格](03-information-architecture-and-interactions.md)，异常状态沿用统一任务状态。Web 主线见 [工作台规格](05-web-agent-workbench.md)。

各流程末尾列主要业务需求；权限、网关、费用、可访问性及运维等横向要求的完整关联在 [需求追踪矩阵](../quality/02-requirements-traceability.md)。

2026-10-22 按 [CLIENT01](../requirements/03-client-execution-amendment.md) 修订：UC02 等云端示例以 Web/Extension 为执行入口；Desktop 在本机运行 Codex，使用相同业务目标及内部模型服务，不沿用云端执行位置。

## 1. UC01 企业首次使用

接受邀请/创建企业 → 进入默认可访问项目及助手 → 直接输入第一项工作目标并附资料，或编辑预填示例 → 按需补阻塞信息 → 在会话旁查看实际产物 → 将有复用价值的资料保存到项目，再邀请同事。

品牌资料可渐进补齐，字体、语言或产品信息确实影响交付时再询问。平台连接不是所有素材任务的前置条件。重复邀请返回已有状态，企业名相同不能合并身份。退出企业不会删除其他成员的任务。

输出：企业、默认项目与助手、会话、首项任务与成果；品牌版本可以在有需要时建立。关联 REQ-001–007、035、051、062、069、072。

## 2. UC02 广告图片与排版

1. 执行人员在 P03 直接描述活动目标并附商品图；已有项目时继承获准品牌资料和预算。
2. Agent 确认影响交付的缺项，列出创意×语言×尺寸矩阵及支持的图片操作。
3. 系统冻结品牌/输入版本并预留费用，任务云端执行。
4. 用户在 P05 查看实际预览、失败单元格及费用，选择修改背景、文案或布局。
5. 文案修改复用已有图像；背景修改创建图像新版本，受影响规格重新排版。
6. 审核人员接受选定版本，下载文件、manifest 和可恢复编辑描述。

异常：字体缺字、商品图不符、媒体接口不可用、费用不足均定位到实际步骤。某个尺寸失败时保留其余产物，用户可只重试失败项。关联 REQ-013–017、022、046、058。

## 3. UC03 短视频及特效

用户选素材和视频目标 → 选择模板成片或已开放的生成式视频 → 确认脚本、字幕、比例和音源 → 形成工程版本 → 渲染/异步生成 → 播放审阅 → 修改与导出。

分镜、生成素材、渲染工程与成片分别标识。模板修改按依赖重新渲染；AI 视频作业存在上游接受状态时，恢复查询原作业。取消后如果上游仍计费，显示等待对账，保留已经生成的可用结果。

高级特效从目录选择输入类型和参数；未开放效果展示准确状态和可交付替代方案。关联 REQ-018–021、009、058。

## 4. UC04 广告数据复盘

1. 分析人员直接提出复盘目标并上传报表，或使用项目已授权的 Google/Meta 账户；实际缺连接时就地引导。
2. 导入预检展示字段映射、日期、币种、归因及错误行；用户确认需要分析的数据范围。
3. 系统完成同步/标准化，冻结快照，展示数据截止时间。
4. 确定性工具计算汇总和变化，Agent 结合证据形成事实、解释和实验建议。
5. 用户从图表或段落点击证据，查看源账户、过滤条件及计算口径。
6. 审核后导出报告，或把建议转为下一轮素材任务并建立 creative ID 映射。

无转化列时仅报告可计算指标；多币种默认分组；平台间归因不直接相加为去重收入。授权失效时可重新连接或导入最新报表，不把旧快照显示为当前实时数据。关联 REQ-023–028、031。

## 5. UC05 SEO 检查

负责人填写站点和允许的页面范围 → 选择 Search Console 及网页诊断能力 → 确认页数上限 → 获取快照 → 查看按 URL 的问题、证据和建议 → 保存修改任务 → 修改后重新检查。

robots、访问限制、登录页面及失败 URL 作为覆盖说明。页面建议与 CMS 写回分开；审核通过不会自动代表页面已发布。检查上限达到时显示剩余范围。关联 REQ-028、029、010。

## 6. UC06 GEO 观测

选择品牌与竞争对手 → 建立问句、语言、地区、模型/产品和检索配置 → 校验内部网关支持范围及费用 → 执行样本 → 查看提及/引用与原始回答证据 → 在同一方法下重复比较。

报告明确 API 观测或消费产品观测，记录模型版本和时间。工具不可访问某产品时不伪造覆盖；样本变化不解释为所有用户的排名变化。关联 REQ-030、043、045。

## 7. UC07 重复流程与周报

用户说“每周一按这个口径做”，或从成功成果保存重复工作 → 查看 Agent/团队、输入输出、工具范围、预算及时间摘要 → 手动验证 → 确认项目时区与触发条件 → 激活 → 查看每次独立运行及异常。高级步骤编排是可选入口。

模板更新生成新版本，既有运行不变。暂停计划停止未来触发；是否取消已运行任务单独选择。漏跑默认只补最近一次；需要补全历史必须明确范围。通知默认在产品内交付；邮件或外部消息渠道需单独配置和授权。

关联 REQ-032–034、010、046、071。

## 8. UC08 仅安装扩展

安装扩展 → 工具栏打开原生右侧对话栏 → 公司登录并选择/继承企业与项目 → 输入消息、选取文件 → 浏览器读取并上传公司云端 → 以成功上传的明确版本作为本次消息附件 → 云端 Codex 执行并流式回复 → 在同一会话连续追问、下载成果。

主体为 ChatGPT 式消息流与底部输入/附件；工作名、预算及完整业务表单不作为发送普通消息的前置。网页上下文按用户主动选择添加；页面内容不能直接发起原生命令。基础文件读取/上传和云端对话无需本地组件，可选目录能力才提示 Host 安装与授权。关联 REQ-036、037、050 及 EXT-C01–C06。

## 9. UC09 扩展加本地桥接

用户安装签名原生组件 → 本地确认企业配对码 → 选择目录及读写范围 → 扩展发现可用设备 → 发起目录任务 → 本地执行器校验命令并处理 → 上传获准结果或保留本地引用。

从 Web 提交的请求不能绕过本地授权；设备离线显示等待。桥接端被浏览器关闭不等于任务删除，云端仍保留状态，后续由设备重新领取未完成命令。关联 REQ-038、040、041。

## 10. UC10 完整 Desktop

安装无边框客户端 → 系统浏览器完成产品登录 → 选择企业/项目、本机工作目录及角色 → 在本机选择受限或完整本机权限 → 客户机启动锁定 Codex 并加载 Skill → 输入目标 → 本机执行文件修改、终端及工具操作 → 查看流式消息、命令和变更 → 本机保存或主动上传选定成果。

完整权限由客户在本机主动授予，可撤回或降级；不是一小时目录桥接，也不自动取得 OS 管理员身份。退出前展示真实本机执行状态，提供等待或终止等已实现选项；窗口关闭不等于已有后台服务。更新包验证通过再应用，失败恢复可运行版本。Agent 本机运行，AI 请求仍经公司内部服务。关联 DESK-L01–L08。

关联 REQ-039–041、043、054。

## 11. UC11 三端接续与执行控制

Web 发起任务 → 需要本地目录时显示等待设备 → 用户在 Desktop 选择范围 → 本地完成步骤 → Web 审阅产物。多个客户端通过版本及事件同步，重复点击不创建重复任务。

用户可在有权限的入口请求取消任务，由当前执行所有者处理；本机任务不能由云端 Worker 再跑一遍。已完成外部动作保留结果；上游无法取消时显示处理中/对账状态。关闭 Web/扩展 UI 不默认取消云任务；Desktop 退出及设备离线不自动云端接管，恢复需本机执行上下文。暂停只在明确检查点生效。关联 REQ-008–010、034、041。

## 12. UC12 撤销、导出与离场

管理员导出项目资料 → 撤销连接与设备 → 停止定时任务 → 发起资料或项目删除 → 查看在线副本清理状态和保留例外 → 必要时完成企业停用。

成员移除立即禁止其新请求，其他成员仍可管理企业产物。在线资源先不可访问再物理清理；恢复备份时应用删除账本。账务与必要审计记录按既定保留政策处理。关联 REQ-003、004、049、050。

## 13. UC13 会话、计划与成果继续工作

从新工作选择默认助手或专业 Agent → 发送目标/附件 → 需要先讨论时选择先计划 → 调整方案后确认当前版本 → 云端执行 → 从右侧选中文本、图片区域或报告证据提出修改 → 在原会话生成引用原产物的新任务 → 搜索、置顶或归档会话。

同一 Agent 的另一个会话有独立讨论上下文。正在运行时发送补充消息必须指向具体任务；普通咨询不隐式新建付费生成。删除会话前说明运行任务与长期记忆的独立处理，默认拒绝直接删除仍有运行任务的会话，用户先取消或等完成后再删除。旧方案确认不可用于修改后的范围。关联 REQ-061、063、067、068。

## 14. UC14 专业角色、技能与方案复用

在能力中心查看专业模板的职责/示例 → 直接使用或复制为项目 Agent → 查看推荐 Skill 的来源、版本、依赖和权限 → 安装、启用并绑定 → 试运行真实样例 → 把被接受的方法保存为候选技能或业务方案 → 具备发布权的人确认后供团队使用。

“已安装”不等于当前 Agent 可调用；缺少账户权限时说明依赖。复制方案不带凭证和私有记忆。同名技能显式选定版本；普通停用不改历史，安全禁用立即阻止后续调用。关联 REQ-062、064、070。

## 15. UC15 专业团队完成复合工作

用户选择已配置的 marketing 团队并提出“分析上周投放并准备新创意” → 协调者给出分工与交付清单 → 分析成员读取获准快照 → 创意成员引用已接受结论制作素材 → 用户查看各成员状态、结果和费用 → 协调者核对清单并汇总审阅。

无依赖任务可以并行，有依赖的创意不提前引用尚未核实的数据。某成员失败显示缺项与局部重试；共享文件写入冲突产生新版本或等待解决。增加成员受权限、预算和并发约束，后台临时子任务不被伪装成持久团队成员。关联 REQ-065、066、067、068。

## 16. UC16 项目共享与同事接续

负责人发布项目说明、资料、技能和连接资源范围 → 同事在项目内新建会话，查看继承摘要 → 引用项目文件工作 → 将已审阅成果及必要说明分享给审核员 → 审核员按选区评论，执行者接受修改并存入项目资料。

共享对象默认是明确选择的成果与必要资料；完整会话只有另行获准时共享。使用个人连接产生的私有内容不能因文件移动而扩大可见范围；新配置仅作用于新运行，安全撤销立即生效。并发修订以基版本校验，拒绝静默覆盖。关联 REQ-002、006、063、065、068、070。

## 17. UC17 选择设计师并交付真实设计

用户从首页或能力中心选择「设计师」→ 查看可交付的主视觉/多尺寸/编辑文件及示例 → 平台固定已发布模板、Codex、设计 Skill 和内部 Image 2 配置 → 附商品图、文案和尺寸 → 按需补资料 → 实际生图/编辑 → 真实字体分层排版 → 预览和选区反馈 → 只改价格或背景 → 下载文件及可恢复工程，存入项目复用。

选择角色自动绑定项目允许的技能，客户无需逐包安装。缺内部 Image 2 或必需技能时说明待接入，不用提示词或其它模型代替已完成图片。复制为企业角色可设品牌、语言和默认规格，升级不改旧运行；角色版需至少十二个不同合格角色，同时覆盖开发和设计。关联 REQ-062、064、073–080。

## 18. UC18 开发与设计角色接续

用户选择全栈/前端/后端/测试角色 → 说明目标和运行环境 → 提供获准代码或新项目范围 → Codex 加载相应工程 Skill → 实现、原生构建与验证 → 交付可运行源码和说明。需要视觉工作时，选择设计角色引用同一获准项目中的需求/资产版本；接受后的视觉包交给前端角色实现，再交测试角色核查。

每个角色记录明确交付、方法版本和费用，引用成果不会复制私有记忆或自动开启并行团队。代码、真实设计文件与运行证据按角色约定验收，依赖缺失清晰阻塞，任务浏览器资源在结束后回收。M2 可将这些持续角色配置为专业团队。关联 REQ-073–076、078–080。

## 19. UC19 管理完整用户与账号状态

平台管理员独立 MFA 登录 → 查看全局去重用户目录 → 按企业、状态、VIP 与活跃筛选 → 打开用户详情，查看所有成员关系及授权字段 → 在权限范围冻结用户或暂停指定企业成员、撤销会话 → 查看在途任务处理与跨端生效记录。

企业管理员不能进入平台后台；企业范围操作不能冻结该用户在其他企业的身份。恢复不重新生成旧会话或连接授权，未获权限的联系字段保持屏蔽。关联 REQ-083–085、094、098、100。

## 20. UC20 查询用户消耗和费用差异

财务从用户或付费企业进入用量 → 选择时段和时区 → 查看已确认扣费、预留及待对账 → 按能力、项目、任务与发起者钻取到原始用量和账本 → 核查价格版本和退款 → 对异常创建对账作业，按权限导出。

团队协调者与成员不重复计费，多企业用户不重复计数。内部成本字段独立授权，未知金额不显示零；用量、现金收入和赠送额度不是同一指标。关联 REQ-046、086、087、094、097、101。

## 21. UC21 主动开通费用与 VIP

管理员选择明确的个人或企业主体 → 查看现有余额、预留和权益版本 → 选择充值、赠送、调整或 VIP 授予 → 填写实际来源、正数金额或有效时段及原因 → 预览影响 → 普通授权操作直接提交，高影响操作按策略审批 → 查询稳定操作结果 → 用户端显示新权益和记录。

充值引用真实确认收款，赠送独立分桶；VIP 与赠送可以组合但各自记录结果和幂等键。延期、换方案、撤销和到期有明确重叠规则；默认无自动续费扣款，余额与预算不会因 VIP 无限制增加。关联 REQ-047、087–089、096、100–102。

## 22. UC22 管理用户内容与运行

内容管理员从用户/项目进入完整资源目录 → 查看授权正文与版本 → 修改可变元数据或以新版本修订文件 → 对问题内容隔离、撤销分享 → 检查搜索、模型和下载入口受限 → 按当前权限恢复或申请生命周期删除；必要时取消任务或暂停未来计划。

客服另走限时只读支持视图；正文、下载与内容修改独立校验。原始文件不覆盖，财务/审计不走通用删除；外部结果未知先对账，不能借重试再次发布。关联 REQ-049、090–092、094–096、100。

## 23. UC23 授予后台权限与审计

安全管理员选择预设或创建角色版本 → 勾选注册动作、字段、数据范围、金额和有效期 → 检查委派上限及风险策略 → 绑定明确管理员 → 用受限身份预览允许动作 → 查询真实操作与拒绝审计 → 撤销绑定并核查旧会话、排队作业及下载。

请求者不可自批高影响授权，不允许通配符、单一 is_admin 或修改审批载荷绕过；审计故障阻止敏感写入。客服视图保留真实身份且不交付用户登录令牌。关联 REQ-083、094–097。

## 24. UC24 批量运营与发布用户端配置

目录管理员建立角色、Skill、公告、帮助或导航草稿 → 指定企业与端预览 → 验证资格、Codex 和内部 AI 约束 → 发布并观察版本传播 → 异常时回滚。具备批量权限的人冻结选择对象及版本 → 提交作业 → 查看逐项成功/失败 → 仅重试获准失败项。

导出按原范围和字段权限生成，下载时再次校验；发布不能直接开放未验证能力，回滚不恢复已撤销权限或旧公开链接。后台页面沿用 CopyPaste 品牌。关联 REQ-044、073、080–082、092、093、097–100、102。

## 25. 全流程品牌与主题

UC01/UC13 的首次使用、UC08 的扩展、UC10 的 Desktop 以及 UC17 的角色/设计流程采用同一 [CopyPaste 品牌规范](07-brand-design-system.md)。用户可切换浅/深/跟随系统，已有输入、任务状态及成果版本保持；客户作品使用客户品牌。窄屏切换会话与成果仍能看见状态并操作，繁中英文、键盘及缩放按 REQ-081/082 验收。

## 26. 全流程异常呈现

| 情况 | 用户可见信息 | 可执行动作 |
| --- | --- | --- |
