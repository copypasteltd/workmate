## 1. 产品范围与管理身份

后台是平台员工使用的独立管理工作区，覆盖用户端 Web、扩展和 Desktop 共用的云端业务对象。Admin 能在授权范围内管理用户、企业、内容、任务、费用、VIP、角色与技能目录、产品配置及运营信息，业务变更经领域服务执行。

平台 Admin 与客户企业的 Owner/Admin 是不同身份域。企业 Admin 只管理所属企业，不因名称相同获得平台后台权限。平台超级管理员可被授予全部已登记管理权限；其他管理员按职责和数据范围分配。后台不能用一个通用 is_admin 布尔值或前端菜单隐藏替代授权。

用户已明确后台能力范围；具体角色组合、金额限额、页面分组和审批阈值是本文件的设计默认。普通且在额度内的人工开通可由获授管理员直接完成，高影响操作按版本化策略处理，不统一要求客户再次批准。

## 3. 用户列表与详情

用户以全局 user_id 唯一标识；一人加入多个企业仍只出现一行，企业成员关系在详情展开。字段包括显示名、脱敏邮箱/电话、注册来源和时间、最近活跃、账号状态、企业数、当前商业权益摘要、指定期间消费、有效额度摘要、创建任务数、风险/支持标签。完整联系方式另有 reveal 权限并记录访问。

筛选包括用户 ID/名称/获准联系方式、注册及活跃区间、账号状态、企业、VIP 类型/状态/到期区间、消费范围、余额不足、异常消费和角色使用情况。支持组合筛选、URL 保留条件、按稳定键排序和服务端分页；总数明确全量还是过滤后可见数量。

A03 详情必须同时显示账号全局状态、当前企业成员状态和计费主体。冻结账号、移除企业成员、停用企业是不同动作，预览受影响登录、任务、计划和其他成员。冻结后撤销会话，阻止新调用；已接受的外部作业按实际状态对账。恢复不恢复已撤销 OAuth、本机授权或被删除内容。

邀请/身份恢复沿用产品身份服务，不给管理员展示密码、OTP、refresh token 或供应商密钥。删除账号先处理资产归属、活跃任务、未结费用和保留例外，最后一位企业 Owner 必须先转移责任。

## 4. 消耗、余额与费用视图

| 概念 | 展示与计算规则 |
| --- | --- |
| 消费金额 | 客户实际计费，关联 usage_event、operation、task 及价格版本；失败调用如已计费同样列入 |
| 内部成本 | 公司实际模型/媒体/资源成本，独立财务权限；不直接作为客户消费金额或公开价格 |
| 估算 / 预留 / 待对账 | 分列展示，不与已确认消费相加冒充实收；未取回数据标为未知或过期 |
| 付费余额 / 赠送额度 | 分桶显示来源、有效期、已预留、可用及回收策略；赠送不是用户付款 |
| 授信 / 期间预算 | 允许后付费的上限 / 期间可花费上限，与充值及 VIP 独立 |
| 个人消费归因 | 按实际发起用户计一次；团队子任务关联主任务，企业消费不按参与成员重复累计 |
| 计费主体 | 明确 user 或 tenant 的 billing_account_id；企业任务默认消费企业账户，不自动使用个人赠额 |

默认时间区间为香港时区自然日的今日、近七日、本月，可选择时间和明确时区；底层保存 UTC。金额沿用 HKD/micros 整数字符串，显示舍入与账单舍入规则一致。数量分别记录 token、图片张数、视频/音频秒数、任务及存储，异构单位不能直接求和。

用量可下钻至任务、attempt、operation、模型/媒体能力、模板/Skill 版本和账本。退款/补偿与原消费关联，支持毛消费、退款和净消费三列；退款不会删除原记录。相同过滤条件的图表、明细、合计与导出使用同一快照及聚合口径，附 as_of、watermark 和是否估算。

## 5. 管理员主动开通费用

用户详情点击「调整费用/额度」→ 明确用户及计费企业/账户 → 选择业务类型 → 输入金额/有效期/原因 → 查看前后差异及政策结果 → 直接执行或进入所需审批 → 展示操作号、流水及用户端生效结果。

| 业务类型 | 管理要求 |
| --- | --- |
| 人工确认充值 | 引用已核实付款记录，已收款与入账状态分别保存；同一外部付款不能重复入账 |
| 赠送/补偿额度 | 创建赠额桶，填写用途、到期及适用能力；可在授权额度内主动为用户开通 |
| 扣减/冲正额度 | 独立 debit/反向账目，引用原记录；拒绝侵占在途预留或让非授信账户超支 |
| 已计费消费退款 | 引用原消费与可退余额，累计不超原额；退回额度与外部支付退款分开跟踪 |
| 调整预算/授信 | 更新版本化上限及生效期；不得以改预算伪造充值或实际付款 |

金额为正的 Money，方向由动作决定，不接受直接 PATCH balance 或删除流水。重复点击、网络超时、队列重放及支付回调返回同一 operation/账目。任何审批匹配具体账户、金额、目标版本、原因和有效期；参数变化重新判定。

例如管理员可给指定企业下的用户任务账户赠送 HKD 500 有效额度，再开通三十天 VIP；这产生两项关联的业务操作，分别有流水/权益版本和结果。页面若提供组合动作，必须显示两项状态，某项失败不能以一个绿色提示宣称全部成功。赠送额度不得出具「用户已付款」记录。

## 6. VIP、方案与有效权限

个人 VIP 与企业方案分别建模；开通必须选择主体、plan_version、开始/结束时间、来源（付费/试用/赠送/补偿）、是否含额度、续费方式及理由。默认人工赠送不自动续费，不暗中建立周期扣款。单独 VIP 标记不自动充值。

支持立即或预约开通、延长、升级、到期降级、暂停、恢复及撤销。续期说明以当前有效结束时间还是指定时间为基准；重叠区间必须合并同类授予或按优先级预览，不能相同权益和赠额重复叠加。编辑已激活授予创建修订/撤销记录，保留原来源。

用户可用权限取：账号与企业有效状态、有效 plan/grant、项目/资源许可、已实测能力、余额/预算和设备授权的交集。VIP 不能解锁未接入 Image 2、未验证 Skill、外部 AI 地址、其他内核、他人项目或未授权本机目录。套餐可以提高配额，不能跳过执行器鉴权。

权益到期或撤销后阻止新的不符合权益的调用；已经计费或已预留的步骤按冻结执行规则安全收尾、对账并保留成果，不凭空取消账目。赠额到期与 VIP 到期分别处理，在途预留继续按原账本核算，不能先回收再消费导致重复扣款。

## 7. 用户端内容完整管理矩阵

内容管理权限允许获授的全局/企业范围内容管理员直接管理对应对象；支持人员仍使用其支持授权，不能借普通故障权限读取全部正文。对象来自业务领域注册表，不是任意数据表 CRUD。

| 用户端对象 | 后台查看 | 后台管理动作及一致性 |
| --- | --- | --- |
| 用户/企业/成员/项目 | 身份、状态、范围、归属 | 停用/恢复、成员范围、责任转移；不得混同全局与企业状态 |
| Agent/专业角色/团队 | 职责、版本、Skill、工具和有效范围 | 创建/修订/启停/调整范围；运行固定版本，安全撤销立即生效 |
| 会话/消息/记忆 | 元数据；有正文权时预览 | 归档、隔离、删除、修订记忆；不伪造用户消息或覆盖已发生执行证据 |
| 品牌/资料/云文件 | 来源、版本、可见范围、获准预览/下载 | 新版本修订、移动、共享撤销、隔离/恢复及生命周期删除 |
| 图片/视频/报告/编辑工程 | 原文件、预览、父版本、引用、评价 | 受控修改为新版本、隐藏/隔离、删除申请；历史版本不可原地覆盖 |
| 任务/步骤/工具事件 | 进度、错误、费用、执行身份 | 取消、允许范围内暂停/恢复/重试；不直接设 succeeded 或重放未知发布 |
| Routine/工作流/解决方案 | 输入输出、触发、授权、版本、历史 | 暂停未来运行、修订新版本、试运行/发布；不静默取消已开始工作 |
| 连接器/外部账户/设备 | 健康、能力、范围和失效原因 | 停用/撤销、请求用户重新授权；不泄露 token 或代签本机目录许可 |
| Skill/模板/能力目录 | 来源、包摘要、资格、依赖和显示信息 | 草稿/预览/发布/下架、安全撤销；Codex、内部网关和资格门槛保持强制 |
| 公告/帮助/示例/菜单/特性 | 语言、位置、目标人群、时间及版本 | 草稿、定时发布、分群/灰度、预览、回滚；入口可见不等于服务端授权 |
| 账单/权益/用量 | 明细、状态、出处及操作 | 经费用/VIP 专用动作调整；无通用内容编辑入口修改账本和审计 |

隔离状态与删除分开：隔离阻止用户端预览、检索、共享、下载及 Agent 后续读取，并保留受控复核与恢复入口；撤销公共分享、索引和缓存权限同时处理。已删除对象按保留期和依赖校验决定能否恢复，已清理原文件不能伪称恢复成功。普通签名 URL 的剩余窗口如实呈现，敏感内容走可即时撤销的代理。

正文、客户 HTML/SVG、媒体及附件在隔离预览环境打开；下载是独立权限。操作对象明确显示 user、tenant、project、版本和范围，禁止误把同名资料或搜索结果作为授权。不能访问的内容不进入搜索摘要、缩略图、计数或导出。

## 8. 权限模型与预设管理员

授权以「管理员主体 + 动作 + 对象/数据范围 + 字段范围 + 当前状态 + 金额/时间/批次约束」判断；显式拒绝优先。平台范围支持 global、指定企业集合及其指定项目，字段单独区分联系方式、客户正文、客户计费、内部成本和导出。global 是明确授予的数据范围，不等于数据库超级用户。

| 角色 | 默认职责 | 明确限制 |
| --- | --- | --- |
| super_admin | 管理全部已注册后台动作、管理员和平台策略 | 不绕过审计、账本一致性、双人审批规则或读取密钥原文 |
| user_operator | 用户/企业元数据、状态、会话撤销、运营标签 | 无资金写入、正文读取及平台授权分配 |
| finance_admin | 消费/账单、额度调整、退款、授信和 VIP | 不直接修改客户正文；操作受其金额和主体范围约束 |
| content_admin | 授权范围内全部用户端内容读取、版本修订、隔离/恢复/删除申请 | 不改账目，不自动获得管理员角色或外部凭证 |
| catalog_manager | 前台配置、官方角色/Skill 发布及方案草稿 | 不直接读取客户内容或修改内部单价；方案正式发布另授权限，角色发布仍需资格验证 |
| support_agent | 元数据、工单、限时客户视角与状态诊断 | 正文需支持授权及额外正文权限；默认无写入、资金、VIP 或发布权 |
| security_admin | 管理员角色/范围、会话撤销、风险策略、审计及紧急停用 | 不默认获得客户正文与商业资金写入；不能批准自己的提权 |
| auditor | 授权范围内审计、政策与脱敏账务复核 | 只读；导出、联系方式和内部成本分别授权 |

权限树使用下列准确机器前缀，完整注册键与八类默认组合见 [权限目录](../contracts/admin-permission-catalog.json)。拥有某一读权限不自动获得同组写权限；范围、字段和风险规则在动作之外继续生效。

## 9. 操作流程、审计与批量管理

读列表直接执行；普通元数据修订使用乐观版本。内容正文访问、资金/VIP、封禁、删除和发布记录原因与工单引用；内容管理员已有有效读取权限时不再要求逐对象客户审批。

风险策略分为直接执行、近期 MFA 后执行、独立审批后执行。大额调整、批量开通、全局封禁、永久删除、管理员提权和价格/权限策略发布可配置为后两类；具体阈值上线前以策略版本冻结。页面在填写后显示实际判定和权限缺口，不隐藏普通人工开通入口。

审批绑定对象清单/参数 hash、版本、请求人、审批人、预算和有效期；审批通过后执行前重新核验权限及当前余额。审计保存 actor_admin_id、实际业务受益人、范围、原因、脱敏前后差异、request/operation/approval、时间及结果；不允许后台删除审计或完整财务事件。

批量动作先冻结目标 ID/版本与预计影响，区分本页选择和筛选下全部对象，提供逐项试算。每项独立鉴权、版本核验和幂等，部分失败可单独重试，取消批次只阻止未执行项。默认单次最多 100 项，超过走分片作业，不允许无界请求。

CSV/报表导出指定允许字段和过滤快照，保护公式单元格注入；异步文件按申请人及当前权限下载，到期失效、撤权立即阻止。支持视角带常驻身份/有效期横幅，默认只读，不复制用户登录 cookie；需要执行动作时以管理员真实身份走同一命令服务。

## 10. 视觉、表格与数据反馈

继承 [品牌规范](07-brand-design-system.md) 的 Logo、浅深主题、色系、字体和圆角；后台正文与密集表格采用无衬线、等宽数字和清楚的列对齐。左侧导航、可折叠筛选栏、指标区、表格和右侧详情抽屉形成主要结构，不另建品牌风格。

1440px 提供完整表格和详情；1024px 收起次要列；768/375px 提供摘要卡与字段展开。确需对照的宽表仅在标明的表格容器内滚动，页面不产生整体横向溢出。全选、展开、排序、分页、审批和表单支持键盘；按钮状态和字段错误以文字说明。

金额/VIP 表单就近显示错误，提交失败后聚焦可链接到具体字段的错误摘要；保留已输入数据和正确的主体。余额、版本或权限改变返回具体冲突及刷新入口，不盲目自动重试财务写入。加载、空数据、无权限、同步延迟、局部失败和后台任务状态分别设计。

图表显示时间区间、币种、口径、数据截至时间，可切换数据表；无权限、未同步与实际零值分别表示。后台不会把静态演示数据标成实时数据。客户作品保持客户品牌，管理员切换主题不修改用户作品。
