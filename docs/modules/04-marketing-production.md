## 1. 制作输入与计划

CreativeBrief 包含目标、受众、产品事实、活动期、渠道、语言、风格、参考资产、禁止项、输出矩阵与预算。ProductionPlan 把交付拆成可追踪单元，每个单元有 specification_id、依赖、能力版本和验收条件。

制作前验证品牌版本、事实有效期、字体覆盖、媒体能力与费用。资料冲突明确显示；对不影响交付的偏好采用用户可修改的默认值，避免反复询问。

## 2. 图片流程

brief → 创意方向 → 图像生成/编辑 → 文件校验 → 商品/Logo/文字组合 → 多尺寸布局 → 质量检查 → 产物版本。模型图像和文字布局分开记录，背景重做与文字微调有不同依赖范围。

首期选定的生成/编辑操作逐项注册，例如 text_to_image、reference_image、replace_background、inpaint、outpaint。具体模型是否支持 mask、透明图或多参考图，必须从内部能力注册表获取；请求不支持的参数应明确拒绝。

输出检查包括文件实际可解码、宽高、透明度、字符及数字准确性、Logo 不变形和商品事实。视觉一致性需用户评审与代表样本评估，不能把模型返回成功当作品牌质量通过。

## 3. 字体与排版

TextLayer 保存原文、语言、font_version、字重、字号、行高、字距、对齐、边框及容器。排版引擎返回行数、包围盒、缺字和溢出。默认允许在明确范围内缩字、换行及调整布局，低于最小字号仍不满足时要求修改文案。

繁中字符不得静默替换为简体；中英混排、数字、货币和全半角通过样例验收。字体来源和使用范围记录在资产中；字体文件不可被未授权项目直接导出。完整字体家族设计作为另立需求处理。

多尺寸适配按各渠道布局模板重新计算，保留人像、商品与关键文字的保护区域。批次每个规格独立状态，局部修改仅失效受影响节点。

## 4. 视频两条生产路径

模板路径：选择模板 → 生成/选择素材 → 组装时间轴 → 字幕与音频 → 预览 → FFmpeg 等原生工具渲染 → 成片校验。生成式路径：准备输入帧/提示与参数 → 经内部服务创建作业 → 查询原作业 → 取回媒体 → 进入同一编辑渲染流程。

视频工程使用有理数帧率与整数帧位置作为剪辑权威时间基准；界面可换算为毫秒。首期示例模板为 9:16、15 秒，真实规格按 brief 确定，不能当作全产品固定限制。

音源、字幕和视频素材版本固定。检查首尾黑帧、音频截断、字幕超出安全区、素材丢失、时长、编码与实际播放。配音和转写是独立 AI 能力；无配音接口时不得把空音轨标为已配音。

## 5. 效果目录

| 类型 | 输入与关键参数 | 首批实现建议 |
| --- | --- | --- |
| 文字出现/强调 | TextLayer、开始帧、持续帧、透明度/位置 | 模板基础动效 |
| 淡入淡出/简单转场 | 相邻 clip、过渡帧数、曲线 | 模板基础动效 |
| 推拉/裁切运动 | 图像、起止裁切区域、持续帧 | 模板基础动效 |
| 背景替换/抠像 | 图片或视频、可选 mask、边缘参数 | 按内部能力逐项开放 |
| 风格或局部编辑 | 来源媒体、区域、提示、约束 | 逐项验证一致性 |
| 视频修复/补帧等 | 视频、处理范围、模型参数 | 在高级媒体阶段单独验收 |

每项效果保存 effect_id、version、输入类型、参数 schema、示例、资源上限、费用单位及是否可取消。非 AI 合成不经过模型网关，效果中涉及 AI 的部分必须经过内部服务。

## 6. 作业、失败与费用

MediaJob 状态独立为 created、submitted、running、cancel_requested、succeeded、failed、cancelled、unknown。请求发出前持久保存 operation_id；超时先查询同一个上游 job，避免重复计费生成。

不支持取消的上游可停止后续步骤，原作业继续核对。超限、失效 URL、内容无效或下载损坏分别错误分类；成功后校验并转存公司管理的对象，不能依赖供应商短期 URL 永久预览。

每次重生成、重渲染有对应成本和原因。用户只改文字时默认复用背景；重生成全部内容需要明确范围与新增费用。

## 7. 产物与验收

图像、视频、字幕、工程及文件清单分别有资产 ID；审阅通过后冻结交付版本。验收参见 TC-015–022，包含真实文件、局部修改、多规格失败、字幕准确性、效果参数与费用可追踪。

## 8. 设计角色绑定与交付分工

预设设计师、品牌、广告、电商、社媒、插画/IP、排版、演示、网页、信息图和视频角色复用本管线，按各自输入和产物约定选择步骤，见 [角色目录](../product/06-role-templates-and-skill-presets.md)。R06 固定 Codex＋设计 Skill＋Image 2；内部文本调度与图片能力分别注册和计费，Image 2 未通过真实生成/编辑验证时不得发布为可直接出图。

演示必须有可编辑 PPTX，图表由计算工具绘制，品牌矢量交付用矢量工具生成，字体排版保留实际文字层；视频角色提供真实模板成片及时间线，生成式媒体按可选依赖分别开放。图片模型的文字结果不替代准确排版；模板不得绕过内部 AI 服务器。角色代表任务、修改及能力缺失用例成为发布资格的一部分。
