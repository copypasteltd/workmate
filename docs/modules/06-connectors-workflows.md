## 1. 连接器契约

每个 ConnectorDefinition 有 provider、version、认证类型、所需权限、支持的读写操作、分页、限流和数据新鲜度策略。Connection 保存企业拥有的授权、可用外部账户、项目可见范围、凭证引用和 auth_version。

统一适配接口为 beginAuth、completeAuth、listResources、sync、revoke、health；这是本产品内部契约，不表示外部供应商有同名 API。各平台字段、scope 和审核条件在接入 PoC 中确认后登记。

## 2. 授权与同步流程

产品用户发起连接 → 服务保存短时 state 和 PKCE/nonce → 平台授权回调 → 核验绑定用户、企业、redirect URI 和一次性状态 → 服务器交换凭证 → 选择获准账户 → 绑定项目 → 首次同步。

Web 在具体步骤需要连接时展示 DependencyRequest 卡片，不要求用户开工前完成全部授权。连接完成只解除相应依赖，复用原任务、预算和检查点；已取消任务不因迟到回调复活。同事复用方案时重新选择自己的或项目获准服务身份，方法共享不会复制凭证。

refresh token 存密钥服务，按连接加锁并使用凭证版本处理轮换；并发刷新不会覆盖新 token。授权错误进入 reauth_required，普通网络错误按有限重试处理，撤销进入 revoked。

同步采用分页检查点和同范围 upsert，保存源 API 版本、游标、行数及数据截止时间。部分分页失败为 partial，不把已完成页面数当整体成功。迟到转化按平台可用策略回补，默认回看窗口为可配置 7 天，实际值由业务口径和配额验证。

## 3. 平台接入说明

| 平台 | 必须核实的条件 | 需要保存的业务口径 |
| --- | --- | --- |
| Google Ads | 当前 Cloud 项目访问级别、OAuth、客户与管理账户范围、目标 API 版本 | 账户时区/币种、转化类型和归因窗口 |
| Meta Ads | 开发者应用、实际权限及审批、广告账户可读范围 | actions/action_values 映射、归因及维度兼容 |
| GA4 | 属性访问及目标指标/维度可用性 | 属性时区、reporting identity、阈值和数据新鲜度 |
| Search Console | 站点授权、查询范围和接口返回限制 | search type、聚合方式、过滤和时间范围 |

Meta 权限与审核细节尚未实测，不能通过模拟适配器宣布正式接入。第一批可用 CSV 验证分析价值，正式连接器验收仍要真实账户读取和撤销证据。

## 4. 流程模板

WorkflowVersion 定义 input_schema、output_schema、steps、依赖、工具范围、预算、失败策略及授权策略。步骤类型初始为 agent_task、query、transform、render、approval、local_command 和 export。

普通用户可以直接在对话中保存重复工作。先形成 RoutineDraft，包含执行 Agent/团队、资料来源、交付位置、时区、预算和频率，确认后发布为稳定版本。简单委派可由一个 agent_task 步骤执行，结构化流程图作为高级编辑；不要求用户手工填写所有内部 schema。每次触发记录独立任务，回到项目及绑定会话查看。

SolutionVersion 将 Agent 模板、SkillVersion、资料要求和连接器定义打包，先展示依赖、试运行、再发布。安装到项目只保存方法引用并生成配置缺口，不复制密钥、个人记忆或源客户文件。技能、方案包和定时运行之间保持版本映射，可追查某次结果由什么方法产生。

允许可读的条件和有上限的迭代；禁止模板携带未审查的任意服务端代码。每次运行冻结模板版本及绑定资源，资源授权仍执行时核查。保存模板不复制平台密钥。

## 5. 定时与事件触发

Trigger 保存项目 IANA 时区、cron/日历表达式、激活区间、模板版本和 catch_up。默认漏跑仅补最近一次，单个触发器最多一个未结束运行；需要并行或补历史时明确设置范围与费用。

触发幂等键为 trigger_id + scheduled_at_utc + workflow_version。时区/表达式修改创建新 TriggerVersion，从新生效时间开始；夏令时重复时刻只按明确策略运行一次，跳过时刻记录 missed。

Webhook 入口验证签名、时间与 event_id，先保存 inbox 再确认接收，重复消息不再创建任务。正式产品默认仅在产品内通知；对外发邮件、消息或发布必须有客户配置和授权。

## 6. 外部副作用

模板中的 publish 或 budget_change 先形成具体动作描述，使用当前企业策略判定授权，参数变化使旧授权失效。动作请求先持久化，再调用平台，成功结果与回执保存。

重试只适用于可证明幂等或只读步骤。结果 unknown 时查询原操作；没有查询能力则暂停该支路并交人工处理。其他无依赖步骤仍可继续，最后按真实交付汇总任务状态。

## 7. 生命周期与验收

停用连接阻止新调用；暂停触发器停止未来运行，但不隐含取消已执行任务。流程删除保留历史运行和模板摘要，凭证及敏感输入按生命周期清理。

验收覆盖 OAuth state 重放、刷新竞争、分页中断、撤销、限流、定时重复、时区切换和外部写入未知结果。事件与控制接口见 [API 说明](../technical/04-api-and-event-contracts.md)。
