Version: 1.0.0. CopyPaste production package.

## Required method

1. Keep approved copy as editable text instead of asking a raster model for exact typography.
2. Verify Traditional Chinese and English wording, prices, numbers and glyph coverage.
3. Use native text/shape layers with consistent alignment and safe margins.
4. Validate the rendered output against the exact input text.
